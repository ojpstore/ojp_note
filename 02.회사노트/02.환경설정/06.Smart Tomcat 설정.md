# 📙 Smart Tomcat 설정 가이드

## 1. ⚙️ 설정 화면 및 항목 설명

![[Pasted image 20260708110345.png]]

![[Pasted image 20260708110515.png]]

- **Tomcat Server**: 설치된 Tomcat의 디렉토리 경로를 지정합니다.
- **Deployment Directory**: 배포할 프로젝트의 웹 리소스(webapp/web) 경로입니다.
- **Context Path**: 애플리케이션 접속을 위한 컨텍스트 경로를 설정합니다. (기본값: `/`)
- **Server Port**: 브라우저에서 접속할 때 사용하는 HTTP 포트입니다.
  - <font color="#ff0000">**Server Port** 는 nexacro 의 Services =>SVC_LOC 의 URL 포트와 동일하게 설정</font>
- **Admin Port**: Tomcat 서버 관리를 위한 포트입니다.

## 2. ℹ VM options 설정

```
-Djavax.net.ssl.trustStore=D:/Wallet_som/truststore.jks
-Djavax.net.ssl.trustStorePassword=비밀번호
```

### 🛡 SSL/TLS 신뢰 저장소 상세 설명

- **`-Djavax.net.ssl.trustStore`**: 서버가 HTTPS 통신 시 상대방의 인증서를 검증하기 위해 사용하는 **신뢰된 인증서 저장소(TrustStore)**의 파일 경로를 지정합니다.
- **`-Djavax.net.ssl.trustStorePassword`**: 지정된 TrustStore 파일에 접근하기 위한 **비밀번호**입니다.
