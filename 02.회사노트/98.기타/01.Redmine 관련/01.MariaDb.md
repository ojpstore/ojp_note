실행

```bash
docker run -d --name mariadb --restart always -p 3307:3306 -v D:\docker\mariadb:/var/lib/mysql -e MYSQL_ROOT_PASSWORD=1234 mariadb:latest --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
```

옵션

- `-d`: 백그라운드 실행
- `--name mariadb`: 컨테이너 이름
- `--restart always`: 컨테이너 자동 재시작
- `-p 3307:3306`: 호스트 3307 포트를 컨테이너 3306 포트로 매핑
- `-v D:\docker\mariadb:/var/lib/mysql`: 데이터 볼륨 바인드 마운트
- `-e MYSQL_ROOT_PASSWORD=1234`: root 패스워드 환경변수
- `--character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci`: MariaDB 문자셋 설정

이 명령은 현재 실행 중인 컨테이너의 모든 설정을 포함합니다.
