실행

```bash
docker run -d --name redmine --restart always -p 8888:3000 -e REDMINE_DB_MYSQL=host.docker.internal -e REDMINE_DB_PORT=3307 -e REDMINE_DB_USERNAME=root -e REDMINE_DB_PASSWORD=1234 -e REDMINE_DB_DATABASE=redmine -e REDMINE_SECRET_KEY_BASE=red1234 -e REDMINE_PLUGINS_MIGRATE=true -v D:\docker\redmine/files:/usr/src/redmine/files -v D:\docker\redmine/themes:/usr/src/redmine/public/themes -v D:\docker\redmine/plugins:/usr/src/redmine/plugins -v D:\docker\redmine/config/configuration.yml:/usr/src/redmine/config/configuration.yml ojpfight/redmine:latest
```

옵션

- `-d` — Run in detached mode
- `--restart always` — Auto-restart on failure
- `-p 8888:3000` — Port mapping (host:container)
- `-e` — Environment variables (DB connection, Redmine config, secret key)
- `-v` — Volume binds (persistent files, themes, plugins, config)

Feel free to ask if you need anything else!
