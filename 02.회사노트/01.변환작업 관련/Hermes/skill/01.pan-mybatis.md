# Skill: pan-mybatis

MyBatis 매퍼 XML의 중복 ID를 추출하고 분석 보고서를 생성합니다.

## Trigger
- MyBatis Mapper XML 내 중복 ID 검사 및 관리가 필요한 경우.

## 작업 절차 (Instructions)
1. **파일 복사**: `C:\panocean-v2\src\main\resources\mappers\som` → `D:\hermes-work\mappers\som`
2. **중복 조사**: 각 XML 파일 내 동일한 `id` 속성을 가진 항목 추출.
3. **결과 생성**: 대상 폴더에 `mybatis_결과.md` 파일 생성.
## 보고서 구성 (Report Format)
### 1. 상단 요약 (Summary)
- **파일건수**: 전체 대상 XML 개수
- **동일건수**: ID와 쿼리 내용이 모두 일치하는 건수
- **상이건수**: ID는 같으나 쿼리 내용이 다른 건수
### 2. 상세 내역 (Detail)
- **파일명 영역**:
    - 배경색: 검정색 (#000000)
    - 기능: 표 접기/펴기 (기본: **접힘**)
    - 표시 정보: `파일명`, `폴더 경로`, `중복 ID 건수` (동일 폰트 설정)
- **분석 결과 표 (Table)**:
    - **컬럼**: 번호, ID명, 쿼리내용, 동일여부
    - **ID명**: `width: 150px`, ID별 색상 구분, (Row Merge 미적용)
    - **동일여부**: 같은 ID 그룹별로 `rowspan` 적용하여 '동일/상이' 표시

### 3. 쿼리 정제 규칙 (Normalization)
1. CDATA, XML 태그, 주석(`--`, `/* */`) 제거.
2. 모든 줄바꿈 및 다중 공백을 단일 공백으로 치환.
3. 요약 없이 전체 순수 SQL 제공.

## 검증 (Verification)
- `D:\hermes-work\mappers\som\mybatis_결과.md` 생성 여부 확인.
