# Skill: pan-service


## 실행 조건 (Trigger)
- `commonDao.getObject`로 래핑되지 않은 `uxbDAO.selectObj` 직접 호출부를 식별해야 할 때.
## 작업 절차 (Procedure)
1. **소스 복제**:
   - `C:/panocean-v2/.../service/` → `D:/hermes-work/service/`
2. **분석 스캔**:
   - Python(`os.walk`)을 사용하여 미래핑된 `uxbDAO.selectObj` 추출.
3. **결과 작성**: `D:\hermes-work\service\service_결과.md` 생성.

## 보고서 형식 (Report Spec)
- **그룹화**: 폴더별 `<details>`, `<summary>` 태그 적용 (접고 펴기).
- **헤더**: 폴더별 발생 횟수 명시.
- **테이블 설정**: 
  - HTML `<table>` 사용 (너비 100%, 열 너비: 15%, 20%, 10%).
  - 파일명별 결정론적 해싱 기반 폰트 색상 적용.
  - 마크다운 깨짐 방지를 위한 파이프(`\|`) 이스케이프 필수.

## 주의 사항 (Pitfalls)
- **인코딩**: Java 파일 읽기 시 반드시 **UTF-8** 적용.
- **스타일**: 일관된 포맷을 위해 마크다운 내 `<style>` 태그 포함.

## 검증 (Verification)
- `service_결과.md` 파일의 정상 생성 및 내용 확인.
