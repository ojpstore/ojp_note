# 테이블 컬럼 조사

    * MyBatis 매퍼 XML의 모든 쿼리 조사
       * 테이블 스키마 파일 : D:\hermes-work\doc\schema.json
    * D:\hermes-work\mappers 폴더 (하위폴더 포함) 에 있는 모든 xml 파일의 모든 쿼리와 테이블 스키마 파일과 비교
    * 해당 xml의 쿼리에 해당하는 테이블에 없는 컬럼이 존재하는 쿼리문 조사
       * xml 쿼리에는 컬럼이 존재하는데 테이블 스키마에는 해당 컬럼이 없는 대상

## 작업 절차

> 파일을 기준으로 D:\hermes-work\mappers\som 안에 있는 모든 mybatis 쿼리 비교 (파일별로)

- select, update,insert 문에서 테이블명
- schema.json 에서 해당 테이블명 찾기
- 스키마 파일에 없는 컬럼 mybatis 쿼리에 존재하는지 비교

## 보고서 구성

> 보고서 출력 : D:\hermes-work\mappers\컬럼조사.md

- 각 파일명 (xml)
- 표로 구현
  - 번호 , id , 라인번호,컬럼, 존재 여부
    - id : 같은면 row merge
    - 존재 여부 : 테이블 스키마에서 해당 컬럼 존재 여부
