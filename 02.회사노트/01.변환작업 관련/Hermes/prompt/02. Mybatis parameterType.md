아래 MyBatis XML 매퍼 파일을 분석해줘.

- 분석 폴더 경로 :D:\hermes-work\panocean-v2\src\main\resources\mappers\som
- 분석 대상: 폴더 경로의 모든 (하위 폴더 포함) 한 xml 파일 대상
  - <insert> 와 <update> 태그만 대상으로 한다.
    분석 절차:
  1. 위 XML 파일에서 모든 <insert id="..."> 와 <update id="..."> 태그의 id를 추출한다.
  2. 각 id에 대해, 해당 id를 호출하는 메서드를 찾는다.
     - 메서드 관련 비교 자바 파일 폴더
       - D:\hermes-work\panocean-v2\src\main\java\com\pan\som\dao
     - D:\hermes-work\panocean-v2\src\main\java\com\pan\som\function
       - D:\hermes-work\panocean-v2\src\main\java\com\pan\som\dao\service
     - 메서드 내부에서 uxbDAO.insert(...) 또는 uxbDAO.update(...)의 두 번째 인자로 해당 id 문자열이 매핑되는 메서드를 찾는다.
  3. 메서드의 두 번째 파라미터 타입을 확인한다.
     - 두 번째 파라미터가 클래스 타입(VO/DTO 등)인 경우만 분석 대상으로 포함한다.
       - VO/DTO 둘다 존재할 경우 DTO 를 추천한다.
     - Map<String, Object> 또는 원시타입(Long, String 등)을 그대로 전달하거나 내부에서 Map을 생성해 전달하는 경우는 제외한다.
  4. 해당 메서드를 호출하는 상위 Java 함수를 Java 소스 전체에서 검색하여 찾는다.
     - 호출 함수는 "파일명 :: 메서드명" 형식으로 표기한다.
     - 호출 함수가 여러 개인 경우 모두 나열하며, 생략하지 않는다.
  5. 두 번째 파라미터 클래스의 네임스페이스 포함 전체 클래스명(FQCN)을 확인한다. - import 구문 또는 클래스 파일 위치를 통해 확인한다.
     분석 결과를 아래 3컬럼 표 형식으로 출력한다:
  - 파일명
  - 표형식
    - id : XML 태그의 id 속성값
    - 호출 함수 : 실제적으로 xml의 "네임스페이스.id"를 호출 java 함수 (복수인 경우 줄바꿈하여 모두 표시,파라미터도 포함) - ex: - uxbDAO.insert("BasicDataAnalysis.portChargeTariffInsert", cbDNewPortChgTariffMVO); - uxbDAO.update("BasicDataAnalysis.portChargeTariffUpdate", cbDNewPortChgTariffMVO);
    - 권장 parameterType (FQCN) : 두 번째 파라미터의 네임스페이스 포함 클래스명
