### ⚙️ 설정 항목 설명
- **Tomcat Server**: 설치된 Tomcat의 디렉토리 경로를 지정합니다.
- **Deployment Directory**: 배포할 프로젝트의 웹 리소스(webapp/web) 경로입니다.
- **Context Path**: 애플리케이션 접속을 위한 컨텍스트 경로를 설정합니다. (기본값: `/`)
- **Server Port**: 브라우저에서 접속할 때 사용하는 HTTP 포트입니다.
- **Admin Port**: Tomcat 서버 관리를 위한 포트입니다.
