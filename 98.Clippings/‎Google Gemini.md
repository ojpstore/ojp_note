obsidian

사용자설정 Gem

Obsidian Dataview 플러그인에서 **노트명(파일명)을 기준으로 정렬** 하고 싶으시군요!

현재 사용 중이신 대시보드 형태의 쿼리(최근 수정, 최근 작성, 폴더별 분류 등)에 바로 적용하실 수 있도록 설정 방법을 알려드릴게요.

### 1\. 쿼리 방식에 따른 정렬 코드 (file.name)

Dataview에서 노트 이름은 `file.name` 이라는 내부 속성을 사용합니다. 기존 작성하신 쿼리문 가장 아랫부분에 아래 코드를 추가하거나 수정해 주시면 됩니다.

#### ① 오름차순 정렬 (가나다, ABC, 숫자 순)

> 보통 이름 정렬을 할 때 가장 기본적으로 사용하는 방식입니다.

```markdown
SORT file.name ASC
```

#### ② 내림차순 정렬 (하파타, ZYX, 역순)

> 최신 번호나 마지막 글자부터 정렬하고 싶을 때 사용합니다.

```markdown
SORT file.name DESC
```

### 2\. 실제 적용 예시 (DQL 기준)

기존에 작성하신 대시보드 코드(아마 `LIST` 또는 `TABLE` 형태일 것입니다)에 아래와 같이 녹여내시면 됩니다.

**예시: '개인노트' 폴더 내 노트를 이름순으로 정렬할 때**

```markdown
\`\`\`dataview
LIST
FROM "개인노트"
SORT file.name ASC
```

```markdown
### 💡 팁: 숫자 정렬 관련 주의사항
현재 노트명 앞에 \`01.\`, \`02.\`, \`03.\` 처럼 숫자를 붙여 관리하고 계신데요, Dataview에서 \`file.name\`은 '텍스트'로 인식합니다. 
* 만약 숫자가 10을 넘어간다면 \`1.\`, \`2.\`, \`10.\` 순이 아니라 문자로 인식되어 \`1.\`, \`10.\`, \`2.\` 순으로 정렬될 수 있습니다. 
* 이를 방지하기 위해 지금처럼 **\`01.\`, \`02.\`, \`10.\`과 같이 자릿수를 맞춰서(패딩)** 이름을 지어주시는 것이 가장 완벽합니다. (아주 좋은 규칙으로 관리하고 계시네요!)
```

노트에서 속성 추가 단축키

obsidian

사용자설정 Gem

옵시디언(Obsidian)에서 노트에 속성(Properties, 과거 Frontmatter)을 바로 추가하는 가장 빠르고 편리한 방법들을 정리해 드릴게요.

## 1\. 기본 기본 단축키 (가장 빠름)

노트 본문 어디서든 아래 단축키를 누르면 노트 맨 위(최상단)로 이동하면서 자동으로 속성 입력창이 생성됩니다.

- **Windows / Linux:** `Ctrl` + `;`
- **Mac:** `Cmd` + `;`

## 2\. 마크다운 기호로 직접 입력하기 (키보드 중심)

단축키를 누르지 않고, 빈 노트 맨 윗줄에서 하이픈 3개를 입력해도 속성 창이 활성화됩니다.

1. 새 노트나 기존 노트의 **맨 첫 번째 줄** 로 이동합니다.
2. 하이픈 3개(`---`)를 입력하고 `Enter` 를 누릅니다.
3. 자동으로 속성(Properties) 박스가 생성됩니다.

## 3\. 명령어 팔레트 활용하기

만약 단축키가 작동하지 않거나 기억이 나지 않을 때는 명령어로 검색할 수 있습니다.

1. `Ctrl` + `P` (Mac은 `Cmd` + `P`)를 눌러 명령어 팔레트를 엽니다.
2. **`속성 추가`** 또는 `Add file property` 라고 검색합니다.
3. 엔터를 누르면 속성이 추가됩니다.

## 💡 전문가의 팁: 단축키가 안 먹힐 때 해결법

만약 `Ctrl + ;`을 눌렀는데도 반응이 없다면, 다른 플러그인과 단축키가 충돌했거나 설정이 해제된 경우일 수 있습니다. 아래 경로에서 단축키를 재지정해 보세요.

> **설정(톱니바퀴) ➔ 단축키(Hotkeys) ➔ 검색창에 '속성 추가' 또는 'Add file property' 검색 ➔ 원하는 단축키로 재지정**
