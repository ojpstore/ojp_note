* 실행
```docker
docker run --name openclaw-gateway --restart unless-stopped -p 18789:18789 -v /volume1/docker/openclaw/config:/home/node/.openclaw -v /volume1/docker/openclaw/workspace:/home/node/.openclaw/workspace -e PLAYWRIGHT_BROWSERS_PATH=/home/node/.cache/ms-playwright -e NODE_ENV=production -e OPENCLAW_GATEWAY_TOKEN=[토큰키] -e OPENCLAW_GATEWAY_MODE=local -e GEMINI_API_KEY=[api-key] ghcr.io/openclaw/openclaw:latest node dist/index.js gateway --bind lan --port 18789 --token [토큰키]
```

**실행 옵션 설명:**
- `--name openclaw-gateway` : 생성될 컨테이너의 이름을 `openclaw-gateway`로 지정합니다.
- `--restart unless-stopped` : 사용자가 명시적으로 중지하지 않는 한, 시스템 재부팅이나 오류 종료 시 컨테이너를 자동으로 재시작합니다.
- `-p 18789:18789` : 호스트 서버의 18789 포트를 컨테이너 내부의 18789 포트와 연결합니다.
- `-v /volume1/.../config:/home/node/.openclaw` : 호스트의 설정 폴더를 컨테이너에 마운트하여 설정 데이터를 영구적으로 보존합니다.
- `-v /volume1/.../workspace:/home/node/.openclaw/workspace` : 호스트의 작업 폴더를 컨테이너에 마운트하여 작업 결과물을 보존합니다.
- `-e PLAYWRIGHT_BROWSERS_PATH=...` : Playwright의 브라우저 다운로드 및 캐시 경로를 지정하는 환경 변수입니다.
- `-e NODE_ENV=production` : Node.js 환경을 운영(프로덕션) 모드로 설정합니다.
- `-e OPENCLAW_GATEWAY_TOKEN=[토큰키]` : OpenClaw 게이트웨이 인증용 토큰 키를 설정합니다.
- `-e OPENCLAW_GATEWAY_MODE=local` : 게이트웨이 실행 모드를 로컬 모드로 설정합니다.
- `-e GEMINI_API_KEY=[api-key]` : LLM(Gemini) 사용을 위한 API 키를 환경 변수로 주입합니다.
- `ghcr.io/openclaw/openclaw:latest` : 실행할 도커 이미지의 주소와 태그(최신 버전)입니다.
- `node dist/index.js gateway ...` : 컨테이너 내부에서 실행할 기본 명령어 및 게이트웨이 구동 옵션(LAN 바인딩, 포트, 토큰 지정)입니다.
