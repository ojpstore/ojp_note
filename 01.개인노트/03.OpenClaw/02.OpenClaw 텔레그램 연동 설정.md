### 1. 텔레그램 봇 생성

1. 텔레그램에서 `@BotFather` 검색 후 대화 시작
2. `/newbot` 입력 및 봇 이름/사용자 이름 설정
   ![[Pasted image 20260709081609.png||600]]
3. 생성된 **HTTP API Token** 복사
   ![[Pasted image 20260709081827.png]]

### 2. Chat ID 확인

1. 텔레그램에서 `@userinfobot` 검색 후 대화 시작
2. 본인의 **Id** (숫자) 확인

### 3. Docker 실행 옵션 추가

기존 실행 명령어에 아래 환경 변수를 추가하여 재실행합니다.

```bash
-e OPENCLAW_TELEGRAM_TOKEN=[봇-토큰] \
-e OPENCLAW_TELEGRAM_CHAT_ID=[사용자-ID]
```

**추가 옵션 설명:**

- `-e OPENCLAW_TELEGRAM_TOKEN` : BotFather로부터 받은 API 토큰입니다.
- `-e OPENCLAW_TELEGRAM_CHAT_ID` : 알림을 받을 사용자의 고유 ID입니다.

### 4. openclaw.json 설정 파일 수정

환경 변수 대신 `openclaw.json` 파일을 직접 수정하여 설정할 수도 있습니다.

```json
{
  ....
  "channels": {
    "telegram": {
      "enabled": true,

      "botToken": "토큰키",

      "dmPolicy": "pairing"
    }
  },
  "commands": {
    "ownerAllowFrom": ["telegram:사용자 id"]
  }
}
```
