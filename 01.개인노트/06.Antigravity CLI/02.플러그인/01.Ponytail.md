## 🛠️ Antigravity CLI에 Ponytail 설치하기

**Ponytail(포니테일)**은 AI 에이전트가 불필요한 코드를 생성하지 않고 최소한의 핵심 로직으로 코드를 작성하도록 유도하는 플러그인입니다.
Antigravity CLI는 `gemini-extension.json` 규격을 공유하므로 아래 명령어로 간편하게 설치할 수 있습니다.
**[현재 버전 (Aggy)]**
```bash
agy plugin install https://github.com/DietrichGebert/ponytail
```

> 💡 **구버전(Gemini CLI) 사용자용 마이그레이션:**
> 현재 `gemini` 바이너리를 사용 중인 경우 아래 명령어를 사용하세요.
> ```bash
> gemini extensions install https://github.com/DietrichGebert/ponytail
> ```

---
## ⚙️ 명령어 및 활용법
설치 완료 후, 슬래시 커맨드 UI에 별도로 나타나지 않더라도 **프롬프트 창에 직접 입력**하면 CLI가 인식합니다.

### 1. 강도 조절 (`/ponytail [강도]`)
AI의 코드 절약(Decision Ladder) 원칙이 적용되는 엄격함을 설정합니다.
- `/ponytail full`: (기본) 일반적인 수준에서 중복이나 과한 설정을 방지합니다.
- `/ponytail ultra`: 가장 강력한 모드입니다. 복잡한 구현보다 필수 기능 위주의 최소 코딩을 강제합니다.
- `/ponytail lite`: 약간의 유연성을 허용하며 작동합니다.

### 2. 코드 다이어트 검토 (`/ponytail-review`)
현재 작성 중인 Diff를 분석하여 **오버엔지니어링** 요소를 잡아냅니다. 불필요한 패키지를 제거하고 표준 라이브러리나 네이티브 기능으로 대체할 수 있는 부분을 제안합니다.
### 3. 프로젝트 코드베이스 진단 (`/ponytail-audit`)
로컬 작업 공간 전체를 스캔하여 **불필요한 추상화 레이어, 중복 코드, 방치된 레거시**를 찾아내고 정리 보고서를 생성합니다.

## 🧐 작동 확인 방법
설치 후 아래와 같은 요청을 던져 포니테일이 올바르게 작동하는지 테스트할 수 있습니다.
> **테스트 프롬프트:** `"간단한 카운트다운 타이머 기능 구현해줘"`

| 구분 | **Ponytail 미적용** | **Ponytail 정상 연동** |
| --- | --- | --- |
| **결과물 특징** | 외부 라이브러리 의존성 추가, 복잡한 포맷팅 함수 등 장황한 코드 생성 | 브라우저/OS 네이티브 기능 활용, 핵심 로직만으로 구성된 간결한 코드 |
| **개발 스타일** | 일반적인 AI의 상세 구현 방식 | **"조용히 한 줄로 끝내는 시니어 개발자"** 스타일 |
