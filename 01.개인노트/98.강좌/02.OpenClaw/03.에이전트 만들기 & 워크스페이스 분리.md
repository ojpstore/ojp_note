## 2. 설정 (openclaw.json)

```json
{
  "gateway": {
    "mode": "local",
    "controlUi": {
      "allowedOrigins": ["http://localhost:3535", "http://127.0.0.1:3535"],
      "allowInsecureAuth": true
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "google/gemini-2.5-flash"
      },
      "models": {
        "google/gemini-2.5-flash": {}
      }
    },
    "list": [
      {
        "id": "assistant",
        "name": "Personal Assistant",
        "workspace": "./workspace/assistant"
      },
      {
        "id": "content-planner",
        "name": "Content Planner",
        "workspace": "./workspace/content-planner"
      },
      {
        "id": "content-editor",
        "name": "Content Editor",
        "workspace": "./workspace/content-editor"
      }
    ]
  }
}
```

## 3.확인

```
openclaw agents list
```
