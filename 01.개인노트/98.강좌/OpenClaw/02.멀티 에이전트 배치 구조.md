## 👉 에이전트별 독립 4대 요소

| 요소          | 설명                                                   |
| :------------ | :----------------------------------------------------- |
| **Workspace** | 어떤 폴더를 작업 공간으로 바라보고 제어할 것인가       |
| **Sessions**  | 어떤 대화 맥락과 작업 기록을 개별적으로 쌓을 것인가    |
| **Tools**     | 해당 에이전트에게 어떤 도구(Tool) 권한을 부여할 것인가 |
| **Model**     | 어떤 AI 두뇌와 역할(System Prompt)을 가질 것인가       |
