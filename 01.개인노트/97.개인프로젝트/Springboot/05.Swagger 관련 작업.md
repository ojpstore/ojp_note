# Spring Boot 3.x Swagger (Springdoc OpenAPI) 설정 가이드

본 문서는 `springboot_boilerplate` 프로젝트에 **Springdoc OpenAPI (Swagger UI)**를 연동하고 설정하는 절차 및 관련 코드 구성을 정리한 가이드입니다.

---

## 1. 프로젝트 환경

- **Spring Boot Version**: `3.4.2`
- **Java Version**: `17`
- **Swagger Library**: `springdoc-openapi-starter-webmvc-ui (v2.8.5)`

---

## 2. 절차별 설정 방법

### Step 1. 빌드 의존성 추가 (`build.gradle`)

Spring Boot 3.x(Jakarta EE) 환경에 호환되는 `springdoc-openapi-starter-webmvc-ui` 의존성을 build.gradle에 추가합니다.

```groovy
dependencies {
    // Spring MVC Web Starter
    implementation 'org.springframework.boot:spring-boot-starter-web'

    // Swagger / Springdoc OpenAPI 3.x UI (Spring Boot 3.x 전용)
    implementation 'org.springdoc:springdoc-openapi-starter-webmvc-ui:2.8.5'

    // 기타 의존성...
}
```

---

### Step 2. Swagger 기본 빈(Bean) 설정 (`SwaggerConfig.java`)

API 문서의 메타정보(타이틀, 설명, 버전 등)를 정의하는 설정 클래스입니다.

- **파일 위치**: `D:/springboot_boilerplate/src/main/java/com/api/config/SwaggerConfig.java`

```java
package com.api.config;

import io.swagger.v3.oas.models.OpenAPI;
import io.swagger.v3.oas.models.info.Info;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class SwaggerConfig {

    @Bean
    public OpenAPI openAPI() {
        return new OpenAPI()
                .info(new Info()
                        .title("API 문서")
                        .description("Spring Boot REST API 문서")
                        .version("1.0.0"));
    }
}
```

#### 주요 특징

- `@Configuration`: Spring 설정 클래스로 등록
- `@Bean OpenAPI openAPI()`: OpenAPI 객체를 생성하여 Swagger 문서의 제목(`title`), 상세 설명(`description`), 버전(`version`)을 통합 관리

---

### Step 3. 컨트롤러 API 문서화 어노테이션 적용

각 REST Controller와 메서드에 Swagger v3 어노테이션을 사용하여 문서 표현력을 높입니다.

- **적용 사례 파일**: `D:/springboot_boilerplate/src/main/java/com/api/sample/controller/RedmineController.java`

```java
package com.api.sample.controller;

import com.api.sample.service.RemineService;
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.Parameter;
import io.swagger.v3.oas.annotations.media.Content;
import io.swagger.v3.oas.annotations.responses.ApiResponse;
import io.swagger.v3.oas.annotations.responses.ApiResponses;
import io.swagger.v3.oas.annotations.tags.Tag;
import lombok.RequiredArgsConstructor;
import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.Collection;

@Tag(name = "Redmine API", description = "Redmine 연동 사용자 조회 API")
@RestController
@RequestMapping(value = "/redmine", produces = MediaType.APPLICATION_JSON_VALUE)
@RequiredArgsConstructor
public class RedmineController {

    private final RemineService service;

    @Operation(summary = "전체 사용자 목록 조회", description = "Redmine의 전체 사용자 목록을 조회합니다.")
    @ApiResponses(value = {
            @ApiResponse(responseCode = "200", description = "성공적으로 사용자 목록을 조회함",
                    content = @Content(mediaType = MediaType.APPLICATION_JSON_VALUE))
    })
    @GetMapping(value = "/users", produces = MediaType.APPLICATION_JSON_VALUE)
    public Collection users(){
        return service.users();
    }

    @Operation(summary = "사용자 단건 상세 조회", description = "사용자 ID(id)를 이용해 특정 Redmine 사용자 정보를 조회합니다.")
    @ApiResponses(value = {
            @ApiResponse(responseCode = "200", description = "성공적으로 사용자 정보를 조회함",
                    content = @Content(mediaType = MediaType.APPLICATION_JSON_VALUE))
    })
    @GetMapping(value = "/users/{id}", produces = MediaType.APPLICATION_JSON_VALUE)
    public Object userById(
            @Parameter(description = "사용자 ID", example = "1")
            @PathVariable int id){
        return service.userById(id);
    }
}
```

#### 주요 어노테이션 설명

|                                  |                     |                                                               |
| -------------------------------- | ------------------- | ------------------------------------------------------------- |
| 어노테이션                       | 위치                | 설명                                                          |
| `@Tag`                           | 클래스 레벨         | Swagger UI 상에서 API 그룹명 및 그룹 설명을 지정              |
| `@Operation`                     | 메서드 레벨         | 엔드포인트의 요약(`summary`) 및 세부 설명(`description`) 지정 |
| `@ApiResponses` / `@ApiResponse` | 메서드 레벨         | HTTP 응답 코드별 설명 지정                                    |
| `@Content`                       | `@ApiResponse` 내부 | 응답 Media Type (`application/json`) 명시                     |
| `@Parameter`                     | 파라미터 레벨       | 파라미터 목적 설명 및 기본 테스트용 예시값(`example`) 제공    |

### Step 4. 구동 완료 시 콘솔 주소 출력 (`SpringbootApiApplication.java`)

SmartTomcat(외장 톰캣 WAR 배포) 및 내장 톰캣 구동 환경 모두에서 구동 완료 시 Swagger UI 접속 링크가 콘솔에 출력되도록 설정합니다.

- **파일 위치**: `D:/springboot_boilerplate/src/main/java/com/api/SpringbootApiApplication.java`

```java
package com.api;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.boot.builder.SpringApplicationBuilder;
import org.springframework.boot.context.event.ApplicationReadyEvent;
import org.springframework.boot.web.servlet.support.SpringBootServletInitializer;
import org.springframework.context.event.EventListener;

@SpringBootApplication
public class SpringbootApiApplication extends SpringBootServletInitializer {

    @Override
    protected SpringApplicationBuilder configure(SpringApplicationBuilder application) {
        return application.sources(SpringbootApiApplication.class);
    }

    public static void main(String[] args) {
        SpringApplication.run(SpringbootApiApplication.class, args);
    }

    @EventListener(ApplicationReadyEvent.class)
    public void onApplicationReady() {
        System.out.println("Application is running at: http://localhost:8081/swagger-ui/index.html");
    }
}
```

## 3. Swagger UI 접속 및 확인 방법

1. 애플리케이션 실행 (SmartTomcat 또는 Java Application 실행)
2. 콘솔 출력 확인:

   ```text
    Application is running at: http://localhost:8081/swagger-ui/index.html
   ```

3. 웹 브라우저에서 아래 URL 접속:
   - **Swagger UI 화면**: [http://localhost:8081/swagger-ui/index.html](http://localhost:8081/swagger-ui/index.html)
   - **OpenAPI JSON 문서**: [http://localhost:8081/v3/api-docs](http://localhost:8081/v3/api-docs)
