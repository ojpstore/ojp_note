# 🛠️ Spring Boot 프로젝트 생성 절차
## 1. 프로젝트 생성 방법

[Spring Initializr](https://start.spring.io/) 사이트 또는 IntelliJ IDEA의 New Project 기능을 사용합니다.

### ✅ 설정 권장사항

- **Project**: `Gradle - Kotlin` (권장)
- **Language**: `Java` (17 이상 권장)
- **Spring Boot**: `3.x.x` (최신 안정화 버전)
- **Packaging**: `Jar`

#### 📦 초기 의존성(Dependencies) 권장
- **Spring Web**: RESTful API 및 웹 개발
- **Lombok**: Getter/Setter 등 반복 코드 자동 생성
- **Spring Data JPA**: 데이터베이스 연산 자동화
- **H2 Database**: 개발 단계에서의 인메모리 DB

> [!info] **Why Gradle (Kotlin DSL)?**
> Groovy보다 가독성이 좋고, IDE의 자동 완성 지원을 완벽하게 받을 수 있어 빌드 스크립트 관리가 훨씬 수월합니다.
