# 🛠️생성 절차

## 👉 1. 생성문

next.js + typescript +pnpm 프로젝트 생성 명령어

```bash
pnpm create next-app@latest
```

명령어 실행 후 대화형 프롬프트에서 **TypeScript**를 `Yes`로 선택하고, 패키지 매니저로 **pnpm**이 사용되는지 확인하세요.
> [!info] **pnpm이란?**
> **pnpm**은 빠르고 효율적인 패키지 매니저입니다. 콘텐츠 주소 지정 저장소(Content-addressable store)를 사용하여 중복된 패키지 설치를 방지하고 디스크 공간을 절약하며, 설치 속도가 매우 빠릅니다.
