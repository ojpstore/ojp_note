# 🛠️ Next.js 프로젝트 생성 절차

## 1. 프로젝트 생성 명령어

TypeScript와 **pnpm**을 사용하는 Next.js 프로젝트 생성 명령어입니다.

```bash

# 현재 디렉터리에 생성 시

pnpm create next-app@latest .



# 새 디렉터리를 만들어 생성 시

pnpm create next-app@latest <project-name>

```

### ✅ 프롬프트 설정 권장사항

명령어 실행 후 나타나는 대화창에서 다음을 확인/선택하세요:

- **Would you like to use TypeScript?** `Yes`

- **Would you like to use ESLint?** `Yes`

- **Would you like to use Tailwind CSS?** `Yes` _(shadcn/ui 사용을 위해 필수)_

- **Would you like to use `src/` directory?** `Yes`

- **Would you like to use App Router?** `Yes`

- **Would you like to customize the default import alias (@/\*)?** `Yes` (`@/*` 권장)

### 💡 Why pnpm?

- **효율적인 디스크 사용**: 콘텐츠 주소 지정 저장소(Content-addressable storage) 하드 링크 방식을 사용해 중복 패키지 설치를 방지하므로 디스크 공간을 대폭 절약합니다.

- **빠른 설치 속도**: 종속성 설치 및 캐싱 알고리즘이 효율적이어서 NPM/Yarn 대비 설치 속도가 매우 빠릅니다.

- **유령 의존성(Phantom Dependency) 방지**: `package.json`에 명시하지 않은 패키지에 임의로 접근하는 문제를 차단하여 더 안전한 프로젝트 환경을 유지합니다.

## 2. 추가 관련 패키지 설치

프로젝트 지침에 따라 **Jotai**(상태 관리) 및 **shadcn/ui**(UI 컴포넌트)를 추가 설치합니다.

### ① Jotai (전역 상태 관리)

원자(Atom) 단위의 가볍고 직관적인 React/Next.js 상태 관리 라이브러리입니다.

```bash

pnpm add jotai

```

### ② shadcn/ui (UI 컴포넌트 라이브러리)

Tailwind CSS와 Radix UI 기반의 커스터마이징이 자유로운 컴포넌트 라이브러리입니다.

```bash

pnpm dlx shadcn@latest init

```

> **shadcn/ui 초기 설정 권장 대화값:**

> - **Style**: Default 또는 New York

> - **Base color**: Zinc / Slate / Neutral 중 선택

> - **CSS file location**: `src/app/globals.css`

> - **Import alias for components**: `@/components`

> - **Import alias for utils**: `@/lib/utils`

개별 컴포넌트(예: Button, Dialog 등) 추가 시:

```bash

pnpm dlx shadcn@latest add button card dialog

```

## 3. 한눈에 보는 Quick Start

```bash

# 1. Next.js 프로젝트 생성

pnpm create next-app@latest



# 2. 전역 상태 관리 패키지 설치

pnpm add jotai



# 3. UI 라이브러리 초기화

pnpm dlx shadcn@latest init

```
