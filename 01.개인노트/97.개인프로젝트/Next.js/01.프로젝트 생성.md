# 🛠️ Next.js 프로젝트 생성 절차

## 1. 프로젝트 생성 명령어

TypeScript와 pnpm을 사용하는 프로젝트 생성 명령어입니다.

```bash
pnpm create next-app@latest
```

### ✅ 프롬프트 설정 권장사항

명령어 실행 후 나타나는 대화창에서 다음을 확인하세요:

- **TypeScript**: `Yes`
- **ESLint / Tailwind CSS**: `Yes` (권장)
- **src/ directory**: `Yes`
- **App Router**: `Yes`
- **Import Alias**: `Yes` (@/\*)

> [!info] **Why pnpm?**
> 콘텐츠 주소 지정 저장소 방식을 사용하여 중복 설치를 방지하므로, 디스크 공간을 절약하고 설치 속도가 매우 빠릅니다.
