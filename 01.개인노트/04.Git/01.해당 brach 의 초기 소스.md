## 🌌 방법 1: git archive 사용하기 (가장 깔끔한 방법)

`.git` 히스토리 폴더 없이, 오직 **그 시점의 순수 소스 코드 파일들만** 새 폴더에 쏙 빼내는 방법입니다.

1. 터미널(또는 Git Bash)을 열고 기존 프로젝트 폴더로 이동합니다.
2. 아래 명령어를 실행합니다.

```
git archive --format=tar <브랜치명> $(git rev-list --max-parents=0 <브랜치명>) | tar -x -C /지정할/새로운/폴더경로
```

### 💡 명령어 원리

- `git rev-list --max-parents=0 <브랜치명>`: 해당 브랜치의 **최초 커밋 ID** 를 자동으로 찾아줍니다.
- `git archive`: 지정한 커밋의 파일들을 묶어줍니다.
- `tar -x -C <경로>`: 묶은 파일들을 지정한 새 폴더에 즉시 압축 해제하여 풀어놓습니다.

## 🌌 방법 2: git clone --depth 사용하기 (새로 다운받는 경우)

만약 기존에 다운받은 폴더가 없고, 원격 저장소(GitHub 등)에서 **최초 커밋만 원격으로 바로 새 폴더에 받고 싶을 때** 유용한 방법입니다.

1. 소스를 받을 새로운 폴더를 만들고, 해당 경로에서 터미널을 엽니다.
2. 아래 명령어를 순서대로 입력합니다.

```
# 1. 새 폴더에 git 저장소 초기화
git init

# 2. 원격 저장소 주소 연결
git remote add origin <저장소_URL>

# 3. 최초 커밋(1개)의 히스토리만 가져오기 (Shallow Fetch)
git fetch --depth=1 origin <브랜치명>

# 4. 가져온 소스를 워킹 디렉토리에 반영
git checkout FETCH_HEAD
```

> **참고:** 이 방법은 히스토리를 1개만 가져오므로 용량을 대폭 아낄 수 있습니다. (다만 완전한 최초 커밋이 아니라, 현재 브랜치의 최신 커밋 기준으로 히스토리를 1개만 가져오는 방식입니다. 만약 '브랜치가 시작된 최초 시점'을 원하신다면 **방법 1** 이나 **방법 3** 을 추천합니다.)

## 🌌 방법 3: 가장 직관적인 수동 방법 (GUI 활용)

명령어가 복잡하게 느껴지신다면 VS Code나 GitHub 웹사이트를 활용하는 가장 편합니다.

### GitHub / GitLab 웹페이지에서 받기

1. GitHub 저장소에서 해당 브랜치로 이동합니다.
2. **Commits** 목록을 누른 뒤, 가장 아래에 있는 최초 커밋(First Commit)을 찾습니다.
3. 최초 커밋 우측의 **`<>` (Browse files)** 버튼을 누릅니다.
4. 그 상태에서 우측 상단의 **Code -> Download ZIP** 을 누르면 최초 소스만 깔끔하게 다운로드할 수 있습니다.

## 🌌 올바른 실행 방법 (3가지 중 선택)

사용하고 계신 터미널 환경에 맞춰 아래 방법 중 하나를 선택해 실행해 주세요.

### 방법 1. 'Git Bash' 터미널을 사용하시는 경우 (가장 추천)

현재 사용하시는 명령어에서 **경로의 슬래시 방향만** 바꾸어 Git Bash에 입력하시면 완벽하게 작동합니다.

```
git archive --format=tar secondary $(git rev-list --max-parents=0 secondary) | tar -x -C D:/panocean-v2-diff
```

- _주의: `D:/panocean-v2-diff` 폴더가 미리 생성되어 있어야 합니다._

### ==방법 2. Windows 일반 '명령 프롬프트(CMD)'를 사용하시는 경우==

CMD에서는 `$()` 문법을 쓸 수 없으므로, 명령어를 **두 단계** 로 나누어 실행해야 합니다.

1. 먼저 `secondary` 브랜치의 최초 커밋 ID를 확인합니다.
   ```
   git rev-list --max-parents=0 secondary
   ```
   _(결과 예시: `a1b2c3d4e5...` 같은 긴 문자열이 출력됩니다.)_
2. 위에서 나온 커밋 ID를 복사해서 아래 명령어에 직접 붙여넣어 실행합니다.
   ```
   git archive --format=tar [확인한_커밋_ID] | tar -x -C D:/panocean-v2-diff
   ```

### 방법 3. 'PowerShell'을 사용하시는 경우

Windows PowerShell을 쓰고 계신다면 `$()` 대신 `()` 를 사용해야 합니다.

```
git archive --format=tar (git rev-list --max-parents=0 secondary) | tar -x -C D:/panocean-v2-diff
```

## 💡 요약 및 체크리스트

- 명령어를 실행하기 전 `D:\panocean-v2-diff` 폴더가 실제로 존재하는지 확인해 주세요 (`tar` 명령어가 폴더를 자동으로 생성해주지 못할 수 있습니다).
- 경로를 작성하실 때는 되도록 `D:/panocean-v2-diff` 처럼 슬래시(`/`)를 사용하는 것이 안전합니다.
