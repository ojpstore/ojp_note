## 1.특정 파일만 선택해서 Merge 하기

1. 먼저 파일을 가져올 대상 브랜치(**B**)로 이동합니다.

   ```bash
   git checkout B
   ```

2. **A** 브랜치에 있는 **a.java** 파일만 현재 브랜치로 가져옵니다. (기존 파일이 있으면 덮어씁니다.)

   ```bash
   git restore --source=A a.java
   ```

3. 변경된 파일을 스테이징하고 커밋합니다.
   ```bash
   git add a.java
   git commit -m "A 브랜치로부터 a.java 파일 가져옴"
   ```

## 2. 특정 확장자(.java) 파일만 Merge 하기

1. 대상 브랜치(**B**)로 이동합니다.

   ```bash
   git checkout B
   ```

2. **A** 브랜치에서 확장자가 **.java**인 모든 파일을 가져옵니다. (현재 브랜치에 이미 존재하는 java 파일들은 A 브랜치의 내용으로 업데이트됩니다.)

   ```bash
   git restore --source=A "*.java"
   ```

3. 변경 사항을 확인 후 커밋합니다.
   ```bash
   git add .
   git commit -m "A 브랜치로부터 모든 java 파일 가져옴"
   ```

## 3. 특정 여러 폴더의 .java 파일만 Merge 하기

1. 대상 브랜치(**B**)로 이동합니다.

   ```bash
   git checkout B
   ```

2. **A** 브랜치의 특정 폴더들 내에 있는 **.java** 파일들을 가져옵니다. (해당 폴더 내 기존 파일이 존재할 경우 A 브랜치 기준으로 동기화됩니다.)

   ```bash
   git restore --source=A "folder1/*.java" "folder2/*.java"
   ```

3. 변경 사항을 스테이징하고 커밋합니다.
   ```bash
   git add .
   git commit -m "A 브랜치의 특정 폴더 내 java 파일들 가져옴"
   ```
