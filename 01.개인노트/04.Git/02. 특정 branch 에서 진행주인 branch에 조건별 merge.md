
## 1.특정 파일만 선택해서 Merge 하기 (A 브랜치의 a.java -> B 브랜치)

1. 먼저 파일을 가져올 대상 브랜치(**B**)로 이동합니다.
   ```bash
   git checkout B
   ```

2. **A** 브랜치에 있는 **a.java** 파일만 현재 브랜치로 가져옵니다.
   ```bash
   git checkout A -- a.java
   ```

3. 변경된 파일을 스테이징하고 커밋합니다.
   ```bash
   git add a.java
   git commit -m "A 브랜치로부터 a.java 파일 가져옴"
   ```

## 2. 특정 확장자(.java) 파일만 Merge 하기

1. 대상 브랜치(**B**)로 이동합니다.
   ```bash
   git checkout B
   ```

2. **A** 브랜치에서 확장자가 **.java**인 모든 파일을 가져옵니다.
   ```bash
   git checkout A -- "*.java"
   ```

3. 변경 사항을 확인 후 커밋합니다.
   ```bash
   git add .
   git commit -m "A 브랜치로부터 모든 java 파일 가져옴"
   ```
