- 실행

```docker
docker run -d --name hermes-agent -p 8642:8642/tcp -p 9119:9119/tcp -v /docker/hermes:/opt/data:rw -e HERMES_AUTH_TOKEN=[토큰키] -e HERMES_DASHBOARD_INSECURE=1 -e HERMES_DASHBOARD=1 -e HERMES_DISABLE_LAZY_INSTALLS=1 nousresearch/hermes-agent:latest gateway run
```

**실행 옵션 설명:**

- `-d`: 컨테이너를 백그라운드에서 실행합니다 (Detached mode).
- `--name hermes-agent`: 생성되는 컨테이너의 이름을 `hermes-agent`로 지정합니다.
- `-p 8642:8642/tcp`, `-p 9119:9119/tcp`: 호스트 포트와 컨테이너 포트(8642, 9119)를 연결(포트포워딩)합니다.
- `-v /docker/hermes:/opt/data:rw`: 호스트의 `/docker/hermes` 디렉터리를 컨테이너의 `/opt/data`에 읽기/쓰기(`rw`) 권한으로 연결(볼륨 마운트)합니다.
- `-e HERMES_AUTH_TOKEN=[토큰키]`: 인증 토큰 값을 환경 변수로 설정합니다.
- `-e HERMES_DASHBOARD_INSECURE=1`: 대시보드의 보안 연결(HTTPS 등)을 우회/비활성화합니다.
- `-e HERMES_DASHBOARD=1`: 대시보드 기능을 활성화합니다.
- `-e HERMES_DISABLE_LAZY_INSTALLS=1`: 플러그인이나 종속성의 지연 설치(Lazy Installs)를 비활성화합니다.
- `nousresearch/hermes-agent:latest`: 사용할 도커 이미지와 태그입니다.
- `gateway run`: 도커 컨테이너가 시작될 때 실행할 Hermes 에이전트 명령어입니다.
