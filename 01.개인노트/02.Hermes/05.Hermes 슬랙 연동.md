# 헤르메스 슬랙 메신저 연결 가이드

[텔레그램 게이트웨이 가이드](https://dante-labs.com/blog/hermes-telegram-gateway) 까지 마치셨다면, 다음 자연스러운 확장은 **팀 협업 채널인 슬랙** 입니다. 텔레그램이 본인 1:1 또는 소수 그룹용이라면, 슬랙은 회사·팀 단위로 "채널 한 줄로 에이전트에게 일 시키기" 흐름을 만드는 자리예요. 본 가이드는 슬랙 워크스페이스 준비부터 첫 응답까지 풀 코스로 다룹니다.

> 💡 **사전 요구사항**: [헤르메스 에이전트 설치 가이드](https://dante-labs.com/blog/hermes-agent-install) 와 [텔레그램 게이트웨이 가이드](https://dante-labs.com/blog/hermes-telegram-gateway) 를 먼저 보고 오세요. `hermes` 명령으로 첫 채팅 + 텔레그램 게이트웨이까지 동작하는 상태에서 시작합니다.

## 슬랙이 텔레그램과 다른 점

슬랙 봇은 텔레그램보다 **설정 단계가 두 배 정도** 됩니다. 입문자가 자주 헷갈리는 자리를 먼저 짚어둘게요.

- **토큰이 두 종류** — 텔레그램은 BotFather 가 토큰 하나만 발급하지만, 슬랙은 두 가지를 동시에 받아야 합니다.
  - **Bot User OAuth Token** (`xoxb-` 로 시작) — 봇이 메시지를 보낼 권한
  - **App-Level Token** (`xapp-` 로 시작) — Socket Mode 로 슬랙 이벤트를 실시간 받을 권한
- **App Manifest 로 14개 권한 한 번에 설정** — OAuth 스코프 · Socket Mode · Slash Commands · App Home 까지 JSON 한 번 붙여넣기로 끝.
- **채널 응답에 봇 멘션 필요** — 슬랙 봇은 텔레그램 그룹과 달리 채널 일반 메시지에는 응답하지 않습니다. **`@Hermes 안녕`** 처럼 멘션해야 응답해요. 응답은 자동으로 스레드로 들어갑니다.
- **채널 초대가 수동** — 슬랙 봇은 채널에 자동 가입 안 됩니다. 채널마다 "채널에 사람 추가" 또는 `/invite @Hermes` 로 수동 초대 필수.
- **App Home Messages Tab 토글** — 이걸 안 켜면 봇이 DM 을 받지 못합니다 ("Sending messages to this app has been turned off" 메시지).

## 1단계. 슬랙 워크스페이스 준비

이미 사용 중인 슬랙 워크스페이스가 있으면 그대로 활용. 없으시면 [slack.com](https://slack.com/) 에서 본인 이메일로 새 워크스페이스를 만드세요. 강의 실습용으로는 "Hermes Lab" 같이 부담 없는 이름으로 신설해도 좋습니다.

## 2단계. Slack App 만들기 (Manifest 활용)

### 2-1. `api.slack.com/apps` 접속

[https://api.slack.com/apps](https://api.slack.com/apps) 에 슬랙 계정으로 로그인. 우측 상단의 **Create an App** 버튼을 클릭합니다.

![api.slack.com/apps 의 Your Apps 화면. 가운데 "Build something amazing" 카드의 Create an App 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-01-create-an-app.png)

### 2-2. 워크스페이스 선택

Create app 모달의 첫 단계(Step 1 of 3). 어느 워크스페이스에 앱을 만들지 묻습니다. 본인 워크스페이스 선택 후 **Next**.

![Create an App 모달 Step 1 of 3 — Pick a workspace to develop your app 화면. 워크스페이스 dropdown 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-03-pick-workspace.png)

> ⚠️ **주의**: 앱이 만들어지는 워크스페이스는 **나중에 바꿀 수 없습니다**. 잘못 선택하면 앱을 통째로 삭제하고 다시 만들어야 해요.

### 2-3. Manifest 받기

터미널로 잠시 돌아가서 한 줄.

```
hermes slack manifest --write
```

복사

›

이 명령이 슬랙 앱의 **OAuth 스코프 14개 + Socket Mode 활성화 + Event Subscriptions + Slash Commands 50개 + App Home 설정** 까지 한 번에 박힌 JSON 파일을 만들어줍니다.

생성 위치는 `~/.hermes/slack-manifest.json`. 이 파일을 텍스트 에디터로 열어 내용 전체를 복사.

### 2-4. Manifest 붙여넣기

Create app 모달이 "Step 2 of 3 — App manifest" 로 넘어가면 JSON 탭이 활성화돼 있습니다. 입력란에 방금 복사한 manifest 내용 전체를 **그대로 붙여넣기** → **Next**.

![Create app from manifest 모달 Step 2 of 3. JSON 탭에 manifest 내용이 붙여진 상태, Next 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-04-manifest-paste.png)

### 2-5. 리뷰 + 생성

Step 3 of 3 "Review summary & create your app". 앱 이름이 `Hermes` 로 보이고, OAuth 탭 아래 Bot Scopes 가 **14개** 박혀 있는지 확인. **Create** 클릭.

![Step 3 of 3 Review summary 화면. 앱 이름 Hermes, Bot Scopes 14개 리스트, Create 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-05-review-summary.png)

앱이 만들어지면 자동으로 앱 관리 페이지(Basic Information)로 이동합니다. 좌측 메뉴에 Settings / Features 가 보이면 정상.

### 2-6. 앱 아이콘 입히기 (소피 얼굴)

앱이 처음 만들어지면 슬랙에서 봇이 기본 회색 아이콘으로 보입니다. 소피에게 얼굴을 입혀 주면 대화창에서 한눈에 알아볼 수 있어요. 좌측 메뉴 **Settings → Basic Information** 으로 가서 페이지를 아래로 내리면 **Display Information** 영역이 있습니다. **App icon** 의 이미지 업로드 칸에 소피 아이콘을 올리고 저장하세요(정사각형 PNG 권장, 512px 이상).

![소피 슬랙 앱 아이콘 — 베이지 재킷을 입고 미소 짓는 일러스트 프로필|300](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/sophie-app-icon.png)

> 💡 이 소피 아이콘은 수강생 전용관 **프로젝트 파일 → `assets/app-icons/sophie.png`** 에서 내려받을 수 있습니다. 같은 이미지를 텔레그램 봇 프로필 사진으로도 그대로 쓸 수 있어요. 나중에 다른 비서 프로필을 만들 때는 같은 폴더에 `프로필명.png` 로 아이콘을 모아 두면 관리가 편합니다.

## 3단계. App-Level Token (xapp-) 발급

Socket Mode 는 슬랙이 이벤트를 헤르메스에게 실시간으로 흘려보내는 통신 방식입니다. 이걸 켜려면 별도 토큰(`xapp-`)이 필요합니다. Manifest 에서 Socket Mode 활성화는 이미 켜뒀으니, 토큰만 발급받으면 됩니다.

### 3-1. Socket Mode 페이지로 이동

좌측 메뉴 **Settings → Socket Mode** 클릭. **Enable Socket Mode** 토글이 켜져 있는지 확인 (Manifest 가 이미 켜놨음).

![앱 관리 페이지의 Socket Mode 섹션. 좌측 Socket Mode 메뉴 강조 + 우측 Enable Socket Mode 토글이 ON 인 상태 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-06-socket-mode-toggle.png)

### 3-2. Generate App-Level Token

Basic Information 페이지 하단 또는 Socket Mode 페이지의 토큰 발급 영역에서 **Generate Token and Scopes** 버튼 클릭.

토큰 발급 모달이 뜨면 다음과 같이 입력.

- **Token Name**: `basic` (자유롭게 — `socket` 같은 이름도 가능)
- **Scopes**: **`connections:write`** 추가 (이게 Socket Mode 가 동작하는 데 필요한 유일한 스코프)

**Generate** 클릭.

![Generate an app-level token 모달. Token Name basic, Scope connections:write 추가된 상태, Generate 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-06b-generate-token-modal.png)

### 3-3. xapp- 토큰 복사

발급된 토큰이 모달에 표시됩니다. **`xapp-1-...` 로 시작하는 긴 문자열**을 통째로 복사해 임시 메모장에 저장. 모달을 닫으면 다시 볼 수 없으니 꼭 이 화면에서 복사.

![App-level token 발급 결과 모달. Token 필드에 xapp-1-... 토큰이 표시되고 Copy 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-07-app-level-token-issued.png)

> ⚠️ **토큰 보안**: `xapp-` 토큰은 봇 자체보다 Socket Mode 연결 권한만 갖지만, 유출되면 본인 봇으로 들어오는 모든 메시지를 가로챌 수 있습니다. 절대 깃 저장소나 공개 채널에 올리지 마세요.

## 4단계. Bot User OAuth Token (xoxb-) 발급

워크스페이스에 봇을 실제로 "설치" 하는 단계입니다. 이 단계가 끝나면 워크스페이스 멤버 목록에 `Hermes` 봇이 등장합니다.

### 4-1. Install to Workspace 클릭

좌측 메뉴 **Settings → Install App** 선택. **Install to [워크스페이스 이름]** 버튼 클릭.

![Install App 페이지. 좌측 Install App 메뉴 강조 + Install to datapod 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-08-install-app.png)

### 4-2. 권한 승인

슬랙 권한 승인 화면이 뜹니다. "Hermes 앱의 Slack 액세스 허용" 안내와 함께 봇이 사용할 권한 요약이 보입니다. **허용** 클릭.

![Slack OAuth 권한 승인 화면 (한국어). "Hermes 앱의 Slack 액세스 허용" 안내와 권한 요약, 허용 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-09-oauth-approve.png)

### 4-3. xoxb- 토큰 복사

설치 완료되면 Installed App Settings 페이지로 돌아옵니다. **OAuth Tokens 섹션의 Bot User OAuth Token** 이 `xoxb-` 로 시작하는 토큰. **Copy** 버튼 클릭해 복사 → 임시 메모장에 저장.

![Installed App Settings 페이지. Bot User OAuth Token (xoxb-...) 입력란과 Copy 버튼 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-10-bot-token-installed.png)

이 시점에 본인이 가진 토큰 두 개.

- `xapp-1-...` (App-Level Token, Socket Mode 용)
- `xoxb-...` (Bot User OAuth Token, 봇 권한용)

둘 다 헤르메스 마법사에 입력합니다.

## 5단계. App Home Messages Tab 켜기 (필수)

**이 단계를 빠뜨리면 DM 으로 봇에게 말을 걸 수 없습니다.** 가장 자주 빠뜨리는 자리.

좌측 메뉴 **Features → App Home** 선택. 페이지 하단의 **Show Tabs** 영역에서 다음 두 가지 확인.

1. **Chat Tab (또는 Messages Tab)** 토글 ON
2. **"Allow users to send Slash commands and messages from the chat tab"** 체크박스 ON

![App Home 페이지. 좌측 App Home 메뉴 강조 + 우측 Show Tabs 섹션의 Chat Tab + Allow users to send Slash commands and messages 체크박스 강조](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-11-app-home-messages.png)

> 💡 매니페스트가 `messages_tab_enabled: true` 와 `messages_tab_read_only_enabled: false` 까지 박아두지만, **"Allow users to send" 체크박스만은 UI 에서 수동으로 켜야** 슬랙 측에 적용됩니다.

## 6단계. user ID 와 channel ID 알아내기

헤르메스가 "누구의 메시지를 받아도 되는지" 와 "기본 응답을 어디로 보낼지" 를 알려면 두 가지 ID 가 필요합니다.

### 6-1. 본인 user ID

슬랙 좌측 사이드바에서 본인 프로필 사진 또는 이름을 클릭합니다.

![슬랙 좌측 사이드바에서 본인 프로필을 클릭하는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-13-member-id-2.png)

우측에 프로필 사이드패널이 열립니다.

![우측에 본인 프로필 사이드패널이 열린 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-13-member-id-3.png)

사이드패널의 **⋮ (점 세 개)** 메뉴를 열어 **"Copy member ID"** 를 클릭하면 클립보드에 user ID 가 복사됩니다. `U` 로 시작하는 11자리 영문·숫자 (예: `U04JXG1LWG2`). 임시 메모장에 저장.

![프로필 사이드패널의 점 세 개 메뉴를 열어 Copy member ID 항목을 클릭하는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-13-member-id-1.png)

### 6-2. 채널 ID

메인 채널(`#general`·`#일반` 또는 본인이 쓸 채널) 이름을 **우클릭** 하면 컨텍스트 메뉴가 열립니다. **"링크 복사"** 선택.

![슬랙 채널 이름을 우클릭해 "링크 복사" 메뉴가 보이는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-12-channel-id-1.png)

복사된 링크는 `https://app.slack.com/client/T.../C04GEC3GQUE` 같은 형식. **마지막 `/` 뒤의 `C` 로 시작하는 11자리 문자열**이 channel ID 입니다.

![복사된 채널 링크 URL 에서 마지막 슬래시 뒤 C 로 시작하는 channel ID 가 보이는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-12-channel-id-2.png)

## 7단계. 헤르메스 게이트웨이에 슬랙 추가

터미널로 돌아와 마법사 실행.

```
hermes setup gateway
```

복사

›

메신저 플랫폼 선택 화면에서 **💼 Slack** 위에서 **Space** 키로 토글. (텔레그램은 이미 켜져 있을 거예요. 그대로 두고 슬랙만 추가.) **Enter** 로 확정.

그 다음 차례로 입력.

### 7-1. Telegram reconfigure 묻는 자리

텔레그램은 이미 설정되어 있으니 `N` 입력해 건너뜁니다.

### 7-2. Slack Bot Token (xoxb-)

4-3 에서 복사한 `xoxb-...` 토큰 붙여넣기.

### 7-3. Slack App Token (xapp-)

3-3 에서 복사한 `xapp-1-...` 토큰 붙여넣기.

### 7-4. Allowed user IDs

6-1 에서 확인한 본인 user ID (예: `U04JXG1LWG2`) 입력. 콤마로 여러 명 가능. 빈 칸이면 워크스페이스 누구나 접근 가능하니 반드시 본인 ID 라도 박아두세요.

### 7-5. 홈 채널 (Home Channel)

헤르메스가 cron 결과·알림을 보낼 기본 채널. 6-2 에서 확인한 채널 ID (예: `C04GEC3GQUE`) 입력. 비워두면 나중에 슬랙 채팅 안에서 `/set-home` 슬래시 명령으로 지정 가능.

### 7-6. 마법사 마무리

마법사가 `✓ Messaging Platforms (Gateway) configuration complete!` 로 끝납니다.

![hermes setup gateway 마법사가 Slack 토글 + xoxb/xapp 토큰 + allowlist + 홈 채널 ID 까지 받고 "Messaging Platforms (Gateway) configuration complete!" 를 표시한 터미널 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-12-wizard.png)

## 9단계. 채널에 봇 초대

**텔레그램과 달리 슬랙 봇은 채널에 자동 가입하지 않습니다.** 사용할 채널마다 수동 초대.

방법 두 가지 중 편한 쪽 선택.

### 9-1. GUI 로 추가 (입문자 권장)

## 10단계. 첫 핸드셰이크

### 10-1. DM 응답

슬랙 좌측 사이드바의 **앱(Apps)** 영역에서 `Hermes` 클릭. DM 창이 열리면 "안녕 헤르메스" 한 줄 입력.

![슬랙 DM 에서 "안녕 헤르메스" 메시지에 헤르메스가 "안녕하세요! 무엇을 도와드릴까요?" 로 응답한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-15-handshake-dm.png)

### 10-2. 채널 응답 — **반드시 봇을 멘션**

채널 응답은 텔레그램과 큰 차이가 있습니다. **`@Hermes` 멘션 없이 "안녕" 만 보내면 헤르메스가 응답하지 않습니다.** 매니페스트가 `message.channels` 이벤트를 구독해도, 슬랙 측에서 채널 일반 메시지는 봇으로 전달하지 않는 동작이에요.

다음과 같이 봇을 멘션해야 합니다.

```
@Hermes 안녕 헤르메스
```

복사

›

헤르메스가 응답을 **스레드 답글로** 보냅니다 (매니페스트의 `reply_to_mode = first` 설정 때문).

![슬랙 채널에서 멘션 없이 보낸 "안녕" 은 응답이 없고, "@Hermes 안녕 헤르메스" 만 스레드 답글로 응답이 도착한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/slack/slack-15-handshake-channel.png)

DM 과 채널 양쪽에서 응답이 도착하면 **앱 생성 + 토큰 발급 + 워크스페이스 설치 + 마법사 등록 + 채널 초대** 전 과정이 정상 동작하는 것입니다.

## 자주 만나는 문제

### A. DM 으로 메시지가 안 보내짐 ("Sending messages to this app has been turned off")

**원인**: 5단계 App Home Messages Tab 의 "Allow users to send Slash commands and messages" 체크박스가 꺼져 있음.

**해결**: Features → App Home → Show Tabs 에서 해당 체크박스 ON. 봇 재설치(Install App → Reinstall to workspace) 후 다시 시도.

### B. 채널에서 멘션 없이 보낸 메시지에 봇이 응답 안 함

**원인**: 슬랙은 채널 일반 메시지를 봇으로 전달하지 않음. 텔레그램 그룹과 가장 큰 차이.

**해결**: `@Hermes <메시지>` 처럼 봇 멘션. 또는 봇이 이미 답한 스레드 안에서 답글로 이어가면 멘션 없이도 흐름 유지.

### C. 마법사에서 `xapp` 또는 `xoxb` 토큰 입력 후 "invalid token" 오류

**원인**: 두 토큰이 서로 자리가 바뀜. 헷갈리기 쉬운 자리.

**해결**: Bot Token 자리에는 **`xoxb-`** 시작 토큰, App Token 자리에는 **`xapp-1-`** 시작 토큰. 다시 입력.

### D. Socket Mode 활성화 후에도 메시지가 안 옴

**원인**: 매니페스트 변경이 슬랙 측에 반영 안 됨. 또는 OAuth 스코프 추가 후 봇 재설치 안 함.

**해결**: Settings → Install App → **Reinstall to workspace** 클릭. 권한 승인 후 게이트웨이 `hermes update` 로 재시작.
