# 헤르메스 텔레그램 메신저 연결 가이드

헤르메스가 설치되고 첫 채팅까지 끝났다면(`hermes` 명령으로 직접 대화), 다음 자연스러운 단계는 **메신저 채널**을 붙이는 일입니다. 본인 휴대폰·노트북 어디서든 텔레그램으로 메시지 한 줄 보내면 헤르메스가 답하는 흐름이 만들어집니다. 이 자료는 가장 입문자 친화적인 채널인 **텔레그램** 을 메인 게이트웨이로 연결하는 풀 코스 가이드입니다.

> 💡 **사전 요구사항**: [헤르메스 에이전트 설치 및 첫 실행 가이드](https://dante-labs.com/blog/hermes-agent-install) 를 먼저 보고 오세요. `hermes setup` 이 끝나고 첫 채팅이 동작하는 상태에서 시작합니다.

## 왜 텔레그램을 메인 채널로 권장하나요

헤르메스가 연결 가능한 메신저는 24가지(Slack · Discord · WhatsApp · Signal · WeChat 등)지만, 입문자에게는 **텔레그램**이 가장 무난합니다.

- **API 발급이 가장 간단함**: 텔레그램 안에서 BotFather 봇과 대화 몇 줄이면 토큰 발급 끝. 별도 개발자 콘솔 가입·심사 없음.
- **그룹·DM 양쪽 지원**: 본인만 쓰는 1:1 DM 도, 팀원들과 함께 쓰는 그룹 채팅방도 모두 같은 봇으로 처리 가능.
- **Privacy Mode 같은 미세 권한 제어**: BotFather 에서 토글 한 번으로 봇이 그룹 일반 메시지도 받을지 멘션 메시지만 받을지 결정.
- **휴대폰 어디서든 접근**: 데스크톱·iOS·Android·웹 모두 동일한 텔레그램 앱에서 대화 가능.

## 1단계. 텔레그램 앱 준비

텔레그램 계정이 이미 있으시면 그대로 사용. 없으시면 [telegram.org](https://telegram.org/) 에서 본인 OS 용 앱을 다운로드해 휴대폰 번호로 가입.

![텔레그램 앱을 처음 실행해 빈 Chats 화면이 표시된 모습](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-app-main.png)

## 2단계. BotFather 로 봇 생성

### 2-1. BotFather 검색

텔레그램 검색창에 **`botfather`** 를 입력하고 **공식 봇 (이름 옆 파란 체크마크)** 선택. 검색 결과 상단의 "CONTACTS AND CHATS" 영역에 나오는 게 공식 봇이고, 그 아래 "GLOBAL SEARCH" 영역에는 위조 봇이 섞여 있으니 체크마크 꼭 확인.

![텔레그램 검색창에서 botfather 를 검색해 공식 BotFather 가 표시된 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-botfather-search.png)

### 2-2. `/newbot` 명령

BotFather 채팅에서 **`/newbot`** 입력. BotFather 가 두 가지를 차례로 묻습니다.

1. **봇 표시 이름** (예: `Dante Hermes Bot`) — 한글·이모지 가능
2. **봇 username** (예: `DanteHermesBot`) — 영문·숫자·언더스코어만, **반드시 `bot` 또는 `_bot` 으로 끝나야 함**

입력이 끝나면 BotFather 가 **토큰**을 발급해줍니다 (`1234567890:ABCdef...` 형식, 약 46자). **이 토큰을 누구에게도 공유하지 마세요** — 봇 권한 전체가 토큰 하나에 담겨 있어서, 유출되면 누구든 본인 봇을 가로챌 수 있습니다.

![BotFather 채팅에서 /newbot 명령으로 봇 이름과 username 을 차례로 입력하는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-newbot-1.png)

![BotFather 가 "Done! Congratulations" 메시지와 함께 봇 토큰을 발급한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-newbot-2.png)

## 3단계. 그룹 채팅방 만들기 + 봇 추가

혼자 쓸 거면 DM 만으로 충분하지만, 헤르메스 자료를 따라 **그룹 채팅방** 도 메인 채널로 등록해두시면 나중에 협업·알림 라우팅에 유리합니다.

### 3-1. 새 그룹 만들기

텔레그램 좌측 상단 **연필 아이콘** → **New Group** 선택. 이름을 정하고 본인 외 멤버는 일단 비워두기.

![텔레그램 화면 우측 상단 연필 아이콘을 클릭해 New Group 메뉴를 연 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-new-group.png)

### 3-2. 봇을 멤버로 추가

그룹 만들고 나서 **멤버 추가** → 검색창에 본인 봇 username (예: `@DanteHermesBot`) → 추가.

![새 그룹의 멤버 추가 검색창에서 본인 봇을 찾아 추가하는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-add-bot-member.png)

### 3-3. 봇 Privacy Mode 끄기 (그룹 응답 필수)

**이 단계를 빠뜨리면 그룹 메시지에 봇이 응답하지 않습니다.** 기본 설정상 봇은 그룹에서 **자기 멘션·답글만** 받습니다. 일반 메시지도 받게 하려면 BotFather 에서 Privacy Mode 를 꺼야 합니다.

1. **@BotFather** 채팅으로 이동
2. `/setprivacy` 입력 → BotFather 가 어떤 봇에 적용할지 묻습니다. 본인 봇 선택.

![BotFather 채팅에서 /setprivacy 명령을 입력하면 어떤 봇에 적용할지 묻는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-botfather-setprivacy-1.png)

3. **Disable** 선택 (기본은 Enabled). BotFather 가 "Success! The new status is: DISABLED." 로 응답하면 적용 완료.

![BotFather 가 Disable 선택 후 "new status is: DISABLED" 로 응답한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-botfather-setprivacy-2.png)

4. 그룹 채팅방에서 봇을 한 번 **제거 후 다시 추가** (변경된 권한이 그룹에 반영되도록).

## 4단계. user ID 와 chat ID 알아내기

헤르메스가 "누가 보낸 메시지를 받아도 되는지" 와 "기본 응답을 어디로 보낼지" 를 알려면 두 가지 ID 가 필요합니다.

- **본인 텔레그램 user ID** (allowlist 용)
- **그룹 채팅방 chat ID** (홈 채널 용)

둘 다 **`User Info · Get ID · IDbot`** 봇으로 한 번에 알 수 있습니다.

### 4-1. 본인 user ID

텔레그램 검색창에 **`User info`** 입력 → "CONTACTS AND CHATS" 영역에 뜨는 **`User Info · Get ID · IDbot`** 선택 (체크마크 확인).

![텔레그램 검색창에서 User info 를 검색해 IDbot 이 결과 상단에 표시된 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-userinfobot-search.png)

채팅을 열고 `/start` 입력. 봇이 즉시 본인 user ID 와 이름·언어 같은 기본 정보를 답해줍니다 (예: `Id: 6367628385`).

![IDbot 에 /start 를 입력하니 Id, First name, Last name, Lang 정보가 답으로 도착한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-userinfobot-userid.png)

### 4-2. 그룹 chat ID

같은 봇을 본인 그룹 채팅방에 잠시 멤버로 추가하면, 그룹의 chat ID 를 알려줍니다. 그룹 chat ID 는 음수로 시작합니다 (예: `-4884689498`).

![IDbot 을 본인 그룹 채팅방에 멤버로 추가하는 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-groupchat-id-1.png)

![그룹에 들어온 IDbot 이 자동으로 그룹 chat ID 를 음수 값으로 응답한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-groupchat-id-2.png)

확인이 끝나면 봇은 그룹에서 제거하셔도 됩니다.

## 5단계. 헤르메스 게이트웨이 설정 (`hermes setup gateway`)

터미널로 돌아와 명령 실행.

```
hermes setup gateway
```

메신저 플랫폼 선택 화면이 뜹니다. 가장 위에 있는 **📱 Telegram** 위에서 **Space** 키로 토글한 뒤 **Enter** 로 확정.

그 다음 차례로 묻는 항목들에 입력합니다.

### 5-1. Telegram bot token

2단계에서 받은 토큰을 그대로 붙여넣기.

![헤르메스 게이트웨이 마법사가 Telegram bot token 을 받고 allowlist 까지 적용한 터미널 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-cli-01-token.png)

### 5-2. Allowed user IDs

4-1 에서 확인한 본인 user ID 입력 (예: `6367628385`). 콤마로 여러 명 가능. 빈 칸으로 두면 누구나 봇에 접근 가능하니 **반드시 입력하시는 것이 안전**합니다.

### 5-3. 홈 채널 (Home Channel)

헤르메스가 cron 결과·알림을 보낼 기본 채널. 본인 DM(user ID)으로 보낼지, 그룹(chat ID)으로 보낼지 선택.

- **개인 사용**: `Y` 눌러 본인 user ID 를 홈 채널로
- **그룹 메인**: `n` 누른 뒤 4-2 의 그룹 chat ID 입력 (음수 그대로, 예: `-4884689498`)

### 5-4. 마법사 마무리

마법사가 `✓ Messaging Platforms (Gateway) configuration complete!` 메시지로 끝납니다.

![게이트웨이 마법사가 끝나고 "Messaging Platforms (Gateway) configuration complete!" 가 표시된 터미널 화면. 그 위에 systemd 서비스 설치 안내가 함께 보임](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-cli-02-config-done.png)

## 6단계. 게이트웨이를 서비스로 등록

마법사 끝에 "Install the gateway as a systemd service?" 가 뜨면 **Y** 를 선택해 백그라운드 서비스로 둘 수 있습니다. 다만 system service 는 sudo 권한이 필요해서 마법사가 직접 만들지는 못합니다. 마법사가 안내해주는 명령은 다음과 같습니다.

```
sudo hermes gateway install --system --run-as-user dante
sudo hermes gateway start --system
```

### 그런데 이 명령이 그대로 동작하지 않는 경우가 많습니다

이 두 명령을 그대로 실행하면 다음 오류를 자주 만나게 됩니다.

```
sudo: 'hermes': command not found
```

`hermes` 를 본인 계정에 설치할 때 `~/.local/bin/` 같은 사용자 홈 영역에 깔리는데, `sudo` 는 보안상 root 의 제한된 PATH 만 사용합니다. 그 안에 `~/.local/bin` 이 없어서 `hermes` 가 안 잡히는 거예요.

해결법은 간단합니다. **`hermes` 의 절대 경로를 직접 확인해 그 경로로 호출**하시면 됩니다.

### 6-1. hermes 절대 경로 확인

```
which hermes
```

다음과 같이 본인 환경의 `hermes` 실행 파일 경로가 출력됩니다.

```
/home/dante/.local/bin/hermes
```

> 💡 사용자명·설치 방식에 따라 경로가 다를 수 있습니다 (예: `/home/USERNAME/.local/bin/hermes`, `/usr/local/bin/hermes`). **본인 환경에서 출력된 경로를 그대로** 다음 단계에서 사용하세요.

### 6-2. 절대 경로로 게이트웨이 설치

위에서 확인한 경로를 `sudo` 뒤에 그대로 박아 실행합니다 (`--run-as-user` 뒤에는 본인 리눅스 사용자명).

```
sudo /home/dante/.local/bin/hermes gateway install --system --run-as-user dante
```

다음과 같이 마법사가 몇 가지를 묻습니다. 모두 `Y` 또는 Enter 로 진행하시면 됩니다.

```
⚠ WSL detected — systemd services may not survive WSL restarts.
    Consider running in foreground instead: hermes gateway run
    Or use tmux/screen for persistence: tmux new -s hermes 'hermes gateway run'

Start the gateway now after installing the service? [Y/n]:
Start the gateway automatically on login/boot with systemd? [Y/n]:

✓ System service installed and enabled!
✓ System service started
```

### 6-3. 게이트웨이 시작

설치 단계에서 자동으로 시작된 경우가 많지만, 그렇지 않다면 한 줄 더.

```
sudo /home/dante/.local/bin/hermes gateway start --system
```

> 💡 **OS·환경별 차이 안내**
>
> - **Linux (WSL2 포함)**: systemd 직접 사용. 위 "절대 경로로 호출" 흐름 그대로.
> - **macOS**: systemd 가 없는 대신 launchd 사용. 마법사가 자동으로 `~/Library/LaunchAgents/ai.hermes.gateway.plist` 를 만들어주고, 제어는 `launchctl kickstart -k "gui/$(id -u)/ai.hermes.gateway"` 같은 명령으로 합니다. (macOS 는 `sudo` 가 필요 없어서 위 PATH 이슈도 해당 없음.)
> - **WSL2**: 마법사가 WSL 환경을 감지해 "systemd 서비스가 WSL 재시작 후 자동 시작 안 될 수 있음" 경고를 띄웁니다. WSL 종료 후 다시 시작할 때마다 수동으로 `sudo systemctl start hermes-gateway` 하시거나, foreground 로 `hermes gateway run` 띄우시면 됩니다.

![sudo hermes gateway install --system 명령으로 systemd 서비스를 설치하고 자동 시작까지 활성화한 터미널 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-cli-03-systemd.png)

서비스 상태 확인.

```
sudo systemctl status hermes-gateway
sudo journalctl -u hermes-gateway -f  # 실시간 로그
```

## 7단계. 텔레그램에서 첫 핸드셰이크

그룹 채팅방 또는 봇 DM 으로 이동해 첫 메시지를 보냅니다.

- DM 권장 흐름: 본인 봇 username 검색 → "START" 버튼 클릭 또는 `/start` 입력
- 그룹 권장 흐름: 봇 멘션 또는 일반 메시지 (Privacy 끈 경우)

### DM 응답 모습

봇 DM 에서 `/start` 와 함께 "안녕" 한 줄을 보내면, 헤르메스가 본인의 이름·역할을 인사로 받아 자기소개·도움 가능 영역을 답신합니다.

![봇 DM 에서 "안녕" 메시지에 헤르메스가 자기소개와 도움 가능 영역으로 응답한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-handshake-dm.png)

### 그룹 채팅방 응답 모습

Privacy 를 꺼두고 본인 user ID 를 allowlist 에 등록한 그룹 채팅방에서 "안녕" 한 줄을 보내면, 멘션 없이도 헤르메스가 응답합니다.

![그룹 채팅방에서 멘션 없이 "안녕" 메시지에 헤르메스가 응답한 화면](https://storage.googleapis.com/dante-edu/hermes-inflearn/telegram/telegram-handshake-group.png)

DM 과 그룹 양쪽 모두에서 응답이 도착하면 **설치 + 인증 + 게이트웨이 + 첫 메시지** 전 과정이 정상 동작하는 것입니다.

## 자주 만나는 문제

### A. 그룹 채팅방에서 봇이 응답 안 함

**원인**: BotFather 의 Privacy Mode 가 기본 Enabled 상태라 봇이 자기 멘션·답글만 받습니다.

**해결**: 3-3 단계의 Privacy 끄기 흐름을 진행. 그 뒤 그룹에서 봇 **제거 → 재추가** 로 권한 변경 반영.

### B. `sudo: hermes: command not found`

root 의 PATH 에 `~/.local/bin` 이 없어 발생합니다. 6단계 본문의 "hermes 절대 경로 확인" 흐름을 그대로 따르세요. 요약하면.

```
which hermes
# 출력 예: /home/dante/.local/bin/hermes

sudo /home/dante/.local/bin/hermes gateway install --system --run-as-user dante
sudo /home/dante/.local/bin/hermes gateway start --system
```

### C. WSL 재부팅 후 게이트웨이 자동 시작 안 됨

WSL 의 systemd 는 호스트 부팅과 분리돼 있어 "부팅 시 자동 시작" 이 항상 동작하진 않습니다. WSL 종료 후 다시 시작할 때마다 다음 명령으로 수동 기동.

```
sudo systemctl start hermes-gateway
```
