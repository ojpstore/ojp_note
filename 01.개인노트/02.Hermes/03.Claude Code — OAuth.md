## Claude Code — OAuth로 API Key 없이 사용 (Claude Max 필요)

Hermes에서 `hermes model → Anthropic OAuth`로 인증하면 Claude Code처럼 Anthropic 구독 계정으로 라우팅됩니다. **단, Claude Max 플랜 + 추가 크레딧을 구매한 경우에만 작동**하며, Claude Pro 구독자는 이 경로를 사용할 수 없습니다. [Nousresearch](https://hermes-agent.nousresearch.com/docs/integrations/providers)

bash

```bash
# OAuth 인증 설정
hermes auth add anthropic --type oauth
```

Max 플랜의 기본 Claude Code 허용량은 소비되지 않으며, 별도로 추가 구매한 크레딧만 사용됩니다. Max + 추가 크레딧이 없다면 `ANTHROPIC_API_KEY`를 사용해야 합니다. [Nousresearch](https://hermes-agent.nousresearch.com/docs/integrations/providers)
