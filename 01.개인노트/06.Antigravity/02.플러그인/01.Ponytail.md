## 🛠️ Antigravity CLI에 Ponytail 설치하기

터미널을 열고 Antigravity CLI 환경에서 아래 명령어를 실행합니다.

Bash

```
agy plugin install https://github.com/DietrichGebert/ponytail
```

> 💡 **참고 (마이그레이션 안내):** 2026년 기준 Gemini CLI가 Antigravity CLI(`agy`)로 완전히 전환되는 과정에 있습니다. 만약 구버전 바이너리(`gemini`)를 여전히 사용 중이시라면 아래 명령어로 설치할 수 있습니다.
>
> Bash
>
> ```
> gemini extensions install https://github.com/DietrichGebert/ponytail
> ```

설치가 완료되면 세션이 시작될 때마다 Ponytail의 핵심 규칙 파일(`gemini-extension.json` 기반 코듈)이 세션 컨텍스트에 항상 자동으로 주입됩니다.

## ⚙️ Antigravity CLI에서의 명령어 사용법

knightli.com

Antigravity CLI의 특성상 설치 후 슬래시 명령어 입력창 메뉴(Slash-command UI popup)에 별도로 표시되지 않을 수 있습니다. 당황하지 마시고 **일반 대화 프롬프트 창에 텍스트로 직접 입력**하시면 CLI가 알아서 감지하고 명령을 수행합니다.

Medium+ 1

### 1. 강도 조절 (`/ponytail [강도]`)

Awesome MCP Servers

AI의 코드 절약 원칙(Decision Ladder)의 엄격함을 조절합니다.

Alpha Match

- `/ponytail full` : 기본 활성화 모드입니다.
  DEV Community
- `/ponytail ultra` : 가장 극단적인 모드입니다. 새로운 코드를 짜기보다 기존 코드 삭제나 단순화를 최우선으로 요구합니다.
  Awesome MCP Servers+ 1
- `/ponytail lite` : 조금 덜 깐깐하게 제안합니다.

### 2. 코드 다이어트 검토 (`/ponytail-review`)

현재 작성 중이거나 변경된 Diff를 분석하여, 불필요한 패키지를 쓰지 않고 네이티브 기능이나 표준 라이브러리로 대체할 수 있는 오버엔지니어링 요소를 짚어줍니다.

### 3. 프로젝트 코드베이스 내의 불필요한 코드 진단 (`/ponytail-audit`)

Awesome MCP Servers

현재 로컬 작업 공간 전체를 스캔하여 쓸데없는 추상화 레이어나 중복, 방치된 레거시를 찾아 정리 보고서를 뽑아줍니다.

Awesome MCP Servers

## 🧐 제대로 작동하는지 확인하는 법

설치 후 Antigravity CLI 창에 다음과 같이 물어보세요.

> `"간단한 카운트다운 타이머 기능 구현해줘"`
>
> Medium

- **Ponytail 미적용:** 새로운 외부 라이브러리를 의존성에 추가하거나 수십 줄짜리 커스텀 포맷팅 함수를 생성합니다.
  knightli.com+ 1
- **Ponytail 정상 연동:** 브라우저/플랫폼 네이티브 기능이나 단 몇 줄짜리 표준 라이브러리(Stdlib) 함수로 구현을 끝내버립니다. 조용히 한 줄로 끝내는 시니어 개발자의 성향을 띠게 되면 성공입니다.
  Alpha Match+ 1
