## 🤔 Unsloth란?

**Unsloth**는 LLM(대규모 언어 모델) 파인튜닝을 2~5배 빠르게, 메모리는 70% 적게 사용할 수 있게 해주는 오픈소스 라이브러리입니다.

### 주요 특징

- ✅ **고속 학습**: 기존 대비 2~5배 빠른 파인튜닝
- 🧠 **메모리 효율**: 70% 적은 VRAM 사용
- 💰 **비용 절감**: 로컬 환경에서 무료로 AI 모델 학습 가능
- 🔓 **오픈소스**: 무료로 사용 가능

### 지원 모델

- Llama 3.2, 3.1, 3
- Mistral, Mixtral
- Gemma 2
- Qwen 2.5
- Phi-3 등

## 🚀 기본 사용법

### 1. 모델 로드

```python
from unsloth import FastLanguageModel
import torch

# 모델 및 토크나이저 로드
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name = "unsloth/llama-3-8b-bnb-4bit",  # 4bit 양자화 모델
    max_seq_length = 2048,
    dtype = None,  # 자동 감지
    load_in_4bit = True,  # 메모리 절약
)
```

### 2. LoRA 어댑터 추가 (파인튜닝용)

```python
model = FastLanguageModel.get_peft_model(
    model,
    r = 16,  # LoRA rank
    target_modules = ["q_proj", "k_proj", "v_proj", "o_proj",
                      "gate_proj", "up_proj", "down_proj"],
    lora_alpha = 16,
    lora_dropout = 0,
    bias = "none",
    use_gradient_checkpointing = True,
    random_state = 3407,
)
```

### 3. 데이터셋 준비

```python
from datasets import load_dataset

# 예시: Alpaca 형식 데이터
dataset = load_dataset("yahma/alpaca-cleaned", split="train")

def formatting_func(examples):
    texts = []
    for instruction, input_text, output in zip(
        examples["instruction"],
        examples["input"],
        examples["output"]
    ):
        text = f"### Instruction:\n{instruction}\n\n"
        if input_text:
            text += f"### Input:\n{input_text}\n\n"
        text += f"### Response:\n{output}"
        texts.append(text)
    return {"text": texts}

dataset = dataset.map(formatting_func, batched=True)
```

### 4. 파인튜닝 실행

```python
from trl import SFTTrainer
from transformers import TrainingArguments

trainer = SFTTrainer(
    model = model,
    tokenizer = tokenizer,
    train_dataset = dataset,
    dataset_text_field = "text",
    max_seq_length = 2048,
    args = TrainingArguments(
        per_device_train_batch_size = 2,
        gradient_accumulation_steps = 4,
        warmup_steps = 5,
        max_steps = 60,
        learning_rate = 2e-4,
        fp16 = not torch.cuda.is_bf16_supported(),
        bf16 = torch.cuda.is_bf16_supported(),
        logging_steps = 1,
        output_dir = "outputs",
        optim = "adamw_8bit",
        seed = 3407,
    ),
)

trainer.train()
```

### 5. 모델 저장 및 추론

```python
# 모델 저장
model.save_pretrained("lora_model")
tokenizer.save_pretrained("lora_model")

# 추론 모드
FastLanguageModel.for_inference(model)

# 텍스트 생성
inputs = tokenizer(
    ["### Instruction:\nWhat is the capital of France?\n\n### Response:\n"],
    return_tensors="pt"
).to("cuda")

outputs = model.generate(**inputs, max_new_tokens=64)
print(tokenizer.decode(outputs[0]))
```

## 📝 주요 기능

### 1. 메모리 최적화

- **4-bit 양자화**: VRAM 사용량 대폭 감소
- **Gradient Checkpointing**: 메모리 효율 증가
- **Flash Attention 2**: 메모리 사용 최적화

### 2. 지원 작업

- ✍️ **Text Generation**: 텍스트 생성
- 💬 **Chat/Instruction Tuning**: 대화형 AI
- 🔄 **Continued Pretraining**: 추가 사전학습
- 🌍 **다국어 지원**: 한국어 포함

### 3. 내보내기 옵션

```python
# GGUF 형식으로 내보내기 (Ollama, LM Studio용)
model.save_pretrained_gguf("model", tokenizer, quantization_method="q4_k_m")

# 16bit 병합 모델
model.save_pretrained_merged("model", tokenizer, save_method="merged_16bit")

# HuggingFace에 업로드
model.push_to_hub("your-username/model-name", token="your-token")
```

## 💡 실전 활용 사례

### 1. 로컬 챗봇 만들기

```python
# Llama 3 기반 한국어 챗봇
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name = "beomi/Llama-3-Open-Ko-8B",
    max_seq_length = 2048,
    load_in_4bit = True,
)

# 대화 형식
prompt = """Below is a conversation between a user and AI assistant.

User: 안녕하세요!
Assistant: 안녕하세요! 무엇을 도와드릴까요?
User: {}
Assistant:"""

inputs = tokenizer(prompt.format("파이썬 공부하는 방법 알려줘"), return_tensors="pt").to("cuda")
outputs = model.generate(**inputs, max_new_tokens=256)
```

### 2. 도메인 특화 모델 학습

- **의료**: 의료 기록 분석
- **법률**: 법률 문서 요약
- **코딩**: 코드 생성 및 디버깅
- **고객지원**: FAQ 자동 응답

### 3. Ollama/LM Studio 연동

```bash
# GGUF 파일 생성 후
ollama create mymodel -f Modelfile
ollama run mymodel
```

## ⚠️ 주의사항

### 성능 관련

- **VRAM 부족**: 배치 크기 줄이기 (`per_device_train_batch_size = 1`)
- **OOM 에러**: `max_seq_length` 줄이기 (2048 → 1024)
- **학습 속도**: GPU 성능에 따라 차이 큼

### 라이선스

- 모델별 라이선스 확인 필수
- 상업적 사용 시 Llama 3 등은 별도 승인 필요
- 파인튜닝한 모델도 원본 라이선스 따름

### 데이터 품질

- **Garbage In, Garbage Out**: 양질의 데이터 필수
- 최소 100~1,000개 이상의 예제 권장
- 데이터 형식 일관성 유지
