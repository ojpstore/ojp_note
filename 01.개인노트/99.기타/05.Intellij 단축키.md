# IntelliJ 단축키

## 가장 자주 사용

| 단축키                          | 기능             | 설명                               |
| ------------------------------- | ---------------- | ---------------------------------- |
| `Ctrl + Space`                  | 기본 자동완성    | 코드 자동완성                      |
| `Shift + Shift`                 | 전체 검색        | 파일, 클래스, 심볼 등 모든 것 검색 |
| `Ctrl + /`                      | 주석 토글        | 라인 주석 추가/제거                |
| `Ctrl + D`                      | 라인 복제        | 현재 라인 복사                     |
| `Ctrl + Y`                      | 라인 삭제        | 현재 라인 삭제                     |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 실행 취소/재실행 | Undo/Redo                          |

## 네비게이션

| 단축키                      | 기능             |
| --------------------------- | ---------------- |
| `Ctrl + N`                  | 클래스 검색      |
| `Ctrl + Shift + N`          | 파일 검색        |
| `Ctrl + E`                  | 최근 파일 목록   |
| `Ctrl + B` / `Ctrl + Click` | 선언부로 이동    |
| `Ctrl + Alt + B`            | 구현체로 이동    |
| `Alt + F7`                  | 사용처 찾기      |
| `Ctrl + H`                  | 클래스 계층 구조 |
| `Ctrl + F12`                | 파일 구조 보기   |

## 편집

| 단축키             | 기능               |
| ------------------ | ------------------ |
| `Ctrl + W`         | 선택 영역 확장     |
| `Ctrl + Shift + W` | 선택 영역 축소     |
| `Ctrl + Alt + L`   | 코드 포맷팅        |
| `Ctrl + Alt + O`   | Import 최적화      |
| `Shift + F6`       | 이름 변경 (Rename) |
| `Ctrl + Shift + U` | 대소문자 전환      |
| `Ctrl + Shift + /` | 블록 주석 토글     |

## 리팩토링

| 단축키                   | 기능                        |
| ------------------------ | --------------------------- |
| `Ctrl + Alt + T`         | 코드 감싸기 (Surround With) |
| `Ctrl + Alt + M`         | 메소드 추출                 |
| `Ctrl + Alt + V`         | 변수 추출                   |
| `Ctrl + Alt + C`         | 상수 추출                   |
| `Ctrl + Alt + F`         | 필드 추출                   |
| `Ctrl + Alt + Shift + T` | 리팩토링 메뉴               |

## 블록 조작

| 단축키                    | 기능                  |
| ------------------------- | --------------------- |
| `Ctrl + NumPad +`         | 블록 펼치기           |
| `Ctrl + NumPad -`         | 블록 접기             |
| `Ctrl + Shift + NumPad +` | 모든 블록 펼치기      |
| `Ctrl + Shift + NumPad -` | 모든 블록 접기        |
| `Ctrl + .`                | 다음 블록 접기/펼치기 |
| `Ctrl + Shift + .`        | 현재 블록 접기/펼치기 |
| `Ctrl + Shift + ↑` / `↓`  | 구문 블록 이동        |
| `Alt + Shift + ↑` / `↓`   | 라인 이동             |
| `Ctrl + Delete`           | 다음 단어까지 삭제    |
| `Ctrl + Backspace`        | 이전 단어까지 삭제    |
| `Ctrl + Shift + Delete`   | 라인 끝까지 삭제      |

## 실행 및 디버깅

| 단축키        | 기능           |
| ------------- | -------------- |
| `Shift + F10` | 실행           |
| `Shift + F9`  | 디버그 실행    |
| `Ctrl + F2`   | 실행 중지      |
| `F8`          | Step Over      |
| `F7`          | Step Into      |
| `Shift + F8`  | Step Out       |
| `Ctrl + F8`   | 중단점 토글    |
| `F9`          | Resume Program |

## 검색 및 바꾸기

| 단축키             | 기능                 |
| ------------------ | -------------------- |
| `Ctrl + F`         | 파일 내 찾기         |
| `Ctrl + R`         | 파일 내 바꾸기       |
| `Ctrl + Shift + F` | 전체 프로젝트 찾기   |
| `Ctrl + Shift + R` | 전체 프로젝트 바꾸기 |

## 멀티 커서 & 선택

| 단축키                   | 기능                     |
| ------------------------ | ------------------------ |
| `Alt + J`                | 다음 동일 단어 선택 추가 |
| `Alt + Shift + J`        | 이전 선택 해제           |
| `Ctrl + Alt + Shift + J` | 모든 동일 단어 선택      |
| `Alt + Shift + Click`    | 멀티 커서 추가           |

## 기타 유용한 단축키

| 단축키             | 기능                         |
| ------------------ | ---------------------------- |
| `Alt + Insert`     | 생성 메뉴 (getter/setter 등) |
| `Ctrl + P`         | 파라미터 정보                |
| `Ctrl + Q`         | Quick Documentation          |
| `Ctrl + Shift + I` | Quick Definition             |
| `Alt + Enter`      | Quick Fix / Intention Action |
| `Ctrl + K`         | Git Commit                   |
| `Ctrl + Shift + K` | Git Push                     |
| `Alt + 1`          | Project 창 토글              |
| `Alt + 7`          | Structure 창 토글            |

## 이동

| 단축키                     | 기능                    |
| -------------------------- | ----------------------- |
| `Ctrl + G`                 | 라인 번호로 이동        |
| `Ctrl + [` / `]`           | 코드 블록 시작/끝 이동  |
| `Ctrl + Shift + Backspace` | 마지막 편집 위치로 이동 |
| `Ctrl + Alt + ←` / `→`     | 이전/다음 탐색 위치     |
