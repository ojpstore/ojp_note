# 

Orca에서 Gitea의 비공개(Private) 저장소 접근 및 REST API를 통한 PR/Commit 상태 연동을 위한 설정 가이드입니다.

---

## 1. Gitea Personal Access Token 발급

1. 사용 중인 **Gitea 웹 콘솔**에 로그인합니다.
    
2. 우측 상단 **프로필 아이콘 > 설정(Settings)**으로 이동합니다.
    
3. **애플리케이션(Applications)** 탭을 선택합니다.
    
4. **새 토큰 생성(Generate New Token)** 섹션에서 설정을 진행합니다:
    
    - **토큰 이름(Token Name)**: `Orca` (임의 지정 가능)
        
    - **권한(Scopes)**: 최소 `repo`(저장소 접근 권한) 및 `read:user` 선택
        
5. **토큰 생성(Generate Token)** 버튼을 클릭한 후, 생성된 토큰 문자열을 복사합니다.
    

---

## 2. Windows 환경 변수 등록

발급받은 토큰과 API 엔드포인트 URL을 시스템 환경 변수에 등록합니다.

### 방법 A: PowerShell 명령어로 등록 (권장)

PowerShell을 실행하고 아래 명령어를 입력합니다:

```powershell
# 1. Gitea Access Token 등록 (필수)
[System.Environment]::SetEnvironmentVariable('ORCA_GITEA_TOKEN', '발급받은_Gitea_토큰_입력', 'User')

# 2. Gitea API Base URL 등록 (선택: 자체 호스팅 또는 API URL 자동 인식이 안 될 경우)
# 예: https://gitea.example.com/api/v1
[System.Environment]::SetEnvironmentVariable('ORCA_GITEA_API_BASE_URL', 'https://자신의_Gitea_주소/api/v1', 'User')
```

---

### 방법 B: Windows GUI(시스템 속성)에서 등록

1. 단축키 `Win + R`을 누르고 `sysdm.cpl` 입력 후 엔터를 실행합니다.
    
2. **고급** 탭으로 이동하여 하단의 **[환경 변수(N)...]**를 클릭합니다.
    
3. 상단 **사용자 변수** 섹션에서 **[새로 만들기(N)...]**를 클릭하여 변수를 추가합니다:
    
    - **변수 이름**: `ORCA_GITEA_TOKEN`
        
    - **변수 값**: 1단계에서 발급받은 Gitea 토큰
        
4. _(필요 시)_ 추가 변수 등록:
    
    - **변수 이름**: `ORCA_GITEA_API_BASE_URL`
        
    - **변수 값**: `https://<Gitea도메인>/api/v1`
        
5. **확인**을 클릭하여 모든 창을 저장하고 닫습니다.
    

---

## 3. Orca 재시작 및 연동 확인

1. 환경 변수 변경 사항을 적용하기 위해 **Orca 애플리케이션을 완전히 종료 후 다시 실행**합니다.
    
2. Orca의 Gitea 설정 화면에서 **[다시 확인]** 버튼을 클릭하여 정상 연동 여부를 확인합니다.
