### ⚠️ 시작 전 준비물 (사전 설치)

Quartz를 빌드하고 웹에 올리려면 컴퓨터에 다음 두 가지 프로그램이 설치되어 있어야 합니다. (이 과정이 처음에는 생소할 수 있지만, 한 번만 설정하면 됩니다.)

1. Node.js: 웹사이트를 빌드(제작)하는 엔진입니다. [Node.js 공식 사이트](https://nodejs.org/)에서 LTS 버전을 설치하세요.
2. Git: 코드의 변경 사항을 저장하고 서버로 전송하는 도구입니다. [Git 공식 사이트](https://git-scm.com/)에서 설치하세요.

---

### 1단계: Quartz 소스 코드 가져오기 (Clone)

먼저 내 컴퓨터에 Quartz의 기본 틀을 가져와야 합니다.

1. 컴퓨터에 폴더를 하나 만듭니다 (예: `C:\Documents\MyWebSite`).
2. 해당 폴더에서 마우스 오른쪽 버튼을 클릭하고 'Open in Terminal' 또는 **'Git Bash Here'**를 선택합니다. (터미널 창이 뜨면 다음 명령어를 입력합니다.)
3. 명령어 입력:

   bash

   ```
   git clone https://github.com/jackyzha0/quartz.git .
   ```

   _(마지막에 한 칸 띄우고 마침표`.`를 꼭 찍어주세요. 현재 폴더에 바로 설치하겠다는 뜻입니다.)_

---

### 2단계: 필수 구성 요소 설치 (Install)

Quartz가 작동하는 데 필요한 부품들을 설치하는 과정입니다.

1. 터미널 창에 다음 명령어를 입력합니다:

   bash

   ```
   npm install
   ```

2. 이 과정은 인터넷 속도에 따라 몇 분 정도 걸릴 수 있습니다. 완료될 때까지 기다려주세요.

---

### 3단계: 내 콘텐츠(Obsidian 노트) 옮기기

이제 Quartz 폴더 안에 여러분의 Obsidian 노트를 넣을 차례입니다.

1. Quartz 폴더 안에 **`content`**라는 폴더가 보일 것입니다.
2. 본인의 Obsidian Vault(보관함) 폴더로 가서, 웹사이트에 올리고 싶은 `.md` 파일들과 이미지 폴더를 복사합니다.
3. 이 파일들을 Quartz의 `content` 폴더 안에 붙여넣기 합니다.
   - 주의: Obsidian의 전체 폴더를 다 넣지 말고, 실제 내용이 담긴 마크다운 파일과 이미지 폴더만 옮기세요. (예: `.obsidian` 폴더나 설정 파일은 넣지 마세요.)

---

### 4단계: 로컬에서 미리보기 (Preview)

웹에 올리기 전에 내 컴퓨터에서 제대로 나오는지 확인하는 단계입니다.

1. 터미널에 다음 명령어를 입력합니다:

   bash

   ```
   npx quartz build --serve
   ```

2. 명령어를 실행하면 `Local: http://localhost:8080` 같은 주소가 뜹니다.
3. 브라우저를 열고 해당 주소로 접속합니다. 화면에 내 노트가 잘 나오는지 확인하세요.
   - 만약 제대로 나온다면 성공입니다! 이제 웹에 올릴 준비가 된 것입니다.

---

### 5단계: GitHub에 내 사이트 올리기 (Deploy)

이제 전 세계 사람들이 볼 수 있게 GitHub Pages를 통해 올릴 차례입니다. (이 과정이 가장 핵심입니다.)

1. GitHub 계정이 필요합니다. (없다면 [github.com](https://github.com/)에서 가입하세요.)
2. GitHub 웹사이트에서 **새로운 저장소(New Repository)**를 만듭니다. 이름은 `my-quartz-site` 등으로 자유롭게 정하세요. (공개/Public으로 설정)
3. 터미널로 돌아와서 다음 명령어를 순서대로 입력합니다 (내 정보를 입력하는 과정입니다):

   bash

   ```
   git add .git commit -m "Initial commit"git branch -M maingit remote add origin https://github.com/본인아이디/저장소이름.gitgit push -u origin main
   ```

   _(참고: `git push` 시 로그인을 요구하는 창이 뜨면 승인해주시면 됩니다.)_

---

### 6단계: 웹사이트 활성화 (GitHub Pages)

마지막으로 GitHub에서 주소를 연결해주는 과정입니다.

1. 방금 만든 GitHub 저장소 페이지로 들어갑니다.
2. 상단의 Settings -> 왼쪽 메뉴의 Pages를 클릭합니다.
3. Build and deployment 섹션에서 Source가 `Deploy from a branch`로 되어 있는지 확인하고, Branch를 `main`으로 선택한 후 Save를 누릅니다.
4. 약 1~3분 뒤에 상단에 `Your site is live at ...`라는 문구와 함께 **웹사이트 주소(URL)**가 나타납니다.

### 💡 초보자를 위한 팁 (자주 묻는 질문)

- Q: 내용을 수정하면 매번 다시 올려야 하나요?
  - A: 네, 내용을 수정하고 `git push`를 하면 웹사이트에 반영됩니다. (수정 후 `git add .`, `git commit -m "수정내용"`, `git push` 순서로 진행)
- Q: 이미지가 안 보여요!
  - A: 이미지 경로가 중요합니다. Obsidian에서 사용하던 경로를 그대로 유지하되, `content` 폴더 안에 이미지 폴더가 포함되어 있어야 합니다.
- Q: 디자인을 바꾸고 싶어요.
  - A: Quartz는 테마 기능이 있습니다. `quartz.layout.ts`나 `quartz.config.ts` 파일을 수정하면 되지만, 초보자라면 기본 테마를 먼저 익숙해지는 것을 추천합니다.

요약하자면: `설치(Node, Git)` → `복제(Clone)` → `설치(npm install)` → `내용 복사(content)` → `미리보기(build --serve)` → `배포(Git Push)` 순서입니다.
