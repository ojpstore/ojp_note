## 사전 준비

다음 프로그램을 먼저 설치하세요:

- **Node.js**: [공식 사이트](https://nodejs.org/)에서 LTS 버전 설치
- **Git**: [공식 사이트](https://git-scm.com/)에서 설치

---

## 1단계: Quartz 설치

```bash
git clone https://github.com/jackyzha0/quartz.git .
npm install
```

> `.` (마침표)를 꼭 포함하세요. 현재 폴더에 바로 설치됩니다.

---

## 2단계: 콘텐츠 추가

1. Quartz 폴더 내 `content` 폴더로 이동
2. Obsidian 노트(.md 파일)와 이미지를 `content` 폴더에 복사
   - `.obsidian` 폴더는 제외

---

## 3단계: 로컬 미리보기

```bash
npx quartz build --serve
```

브라우저에서 `http://localhost:8080` 접속하여 확인

---

## 4단계: GitHub 배포

### 4-1. GitHub 저장소 생성

- [GitHub](https://github.com/)에서 새 저장소 생성 (Public)

### 4-2. Git 업로드

```bash
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/사용자명/저장소명.git
git push -u origin main
```

### 4-3. GitHub Pages 활성화

1. GitHub 저장소 → **Settings** → **Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` 선택 후 **Save**
4. 1~3분 후 사이트 URL 생성 완료

---

## 업데이트 방법

내용 수정 후 다음 명령어로 재배포:

```bash
git add .
git commit -m "수정 내용"
git push
```

## 자주 묻는 질문

**Q. 이미지가 안 보여요**

- 이미지가 `content` 폴더 내에 있는지 확인
- Obsidian에서 사용한 경로 그대로 유지

**Q. 디자인 변경 방법은?**

- `quartz.config.ts` 또는 `quartz.layout.ts` 파일 수정
- 초보자는 기본 테마 사용 권장
