> Windows 환경에서 다른 경로의 폴더를 특정 위치에 실제 있는 것처럼 연결하는 방법 가이드

---

## 1️⃣ 디렉터리 정션 (Junction) - **추천**

### ✅ 특징

- **관리자 권한 불필요**
- 파일 탐색기, VS Code 등 모든 프로그램에서 실제 폴더처럼 인식
- 로컬 드라이브 간 연결만 가능 (네트워크 경로 불가)
- 삭제 시 원본 폴더에 영향 없음 (연결만 삭제됨)

### 📍 실행 방법

1. `Win + R` → `cmd` 입력 후 실행
2. 다음 명령어 입력:

```cmd
mklink /J "연결할 위치" "원본 폴더 위치"
```

### 💡 실제 사용 예시

**상황**: 바탕화면의 이미지 폴더를 프로젝트 폴더에서 사용하고 싶을 때

```cmd
mklink /J "D:\orca-work\next-app\public\images" "C:\Users\ojpfi\Desktop\MyImages"
```

**결과**: `D:\orca-work\next-app\public\images`로 접근하면 실제로는 `C:\Users\ojpfi\Desktop\MyImages`의 내용이 보임

### 🗑️ 연결 삭제 방법

```cmd
rmdir "D:\orca-work\next-app\public\images"
```

또는 파일 탐색기에서 해당 폴더를 `Delete` (원본은 안전)

---

## 2️⃣ 심볼릭 링크 (Symbolic Link)

### ✅ 특징

- **관리자 권한 필요**
- 네트워크 경로 연결 가능
- 상대 경로 지원
- 파일/폴더 모두 연결 가능

### 📍 실행 방법

1. `Win + X` → **명령 프롬프트(관리자)** 또는 **PowerShell(관리자)** 실행
2. 다음 명령어 입력:

```cmd
mklink /D "연결할 위치" "원본 폴더 위치"
```

### 💡 실제 사용 예시

```cmd
mklink /D "C:\MyProjects\assets" "D:\SharedResources\assets"
```

---

## 📌 두 방법 비교

| 구분          | 디렉터리 정션 (/J) | 심볼릭 링크 (/D) |
| ------------- | ------------------ | ---------------- |
| 관리자 권한   | 불필요 ✅          | 필요 ⚠️          |
| 네트워크 경로 | 불가               | 가능             |
| 사용 난이도   | 쉬움               | 쉬움             |
| 호환성        | 우수               | 우수             |
| **추천도**    | ⭐⭐⭐⭐⭐         | ⭐⭐⭐⭐         |

---

## ⚠️ 주의사항

- 연결 폴더 삭제 시 원본은 영향 없음 (안전)
- 원본 폴더 이동/삭제 시 연결이 끊어짐
- 연결 생성 전 대상 경로에 같은 이름의 폴더가 없어야 함
