## 🫷 CSS 스니펫을 이용해 모든 `attach` 폴더 숨기기

이 방법을 사용하면 폴더 위치가 최상위든, 하위 폴더 내부든 상관없이 이름이 `attach`인 폴더는 파일 탐색기 목록에서 전부 숨겨집니다.

#### 1. CSS 스니펫 파일 생성

1. 옵시디언 **설정(톱니바퀴)** → **모양 (Appearance)** 탭으로 이동합니다.
2. **CSS 스니펫 (CSS snippets)** 항목 오른쪽에 있는 폴더 아이콘(스니펫 폴더 열기)을 클릭합니다.
3. 열린 폴더 안에 새 텍스트 파일을 만들고, 파일 이름을 `hide-attach.css`로 변경합니다. (확장자가 `.css`여야 합니다.)

#### 2. 코드 입력

생성한 `hide-attach.css` 파일을 메모장이나 텍스트 편집기로 열고 아래 코드를 복사해서 붙여넣은 뒤 저장합니다.

CSS

```css
/* 경로 끝이 /attach 이거나, 폴더명이 정확히 attach인 폴더 숨기기 */
div.nav-folder-title[data-path$="/attach"],
div.nav-folder-title[data-path="attach"],
div.nav-folder-title[data-path$="/attach"] + div.nav-folder-children,
div.nav-folder-title[data-path="attach"] + div.nav-folder-children {
  display: none !important;
}
```

#### 3. 스니펫 활성화

1. 다시 옵시디언 **설정 → 모양 → CSS 스니펫**으로 돌아옵니다.
2. 새로고침 버튼(새로고침 아이콘)을 누르면 `hide-attach` 스니펫이 목록에 나타납니다.
3. 스니펫 옆의 **토글 스위치를 켜서 활성화**합니다.

### 💡 추가 팁: 검색 결과나 퀵 스위처에서도 완전히 제외하려면

위의 CSS 스니펫은 **왼쪽 파일 탐색기 목록**에서만 안 보이게 해줍니다.

검색, 그래프 뷰, 퀵 스위처(`Ctrl + O` / `Cmd + O`)에서도 완전히 제외하려면 아래 설정을 추가로 진행해 주세요.

1. 설정 → 파일 및 링크 (Files & links)로 이동합니다.
2. **제외된 파일 (Excluded files)** 항목 옆의 **[관리]** 버튼을 클릭합니다.
3. 패턴 입력창에 `**/attach` 또는 `attach`를 입력하여 추가합니다.
