| :--- | :--- | :--- |

| **editing-toolbar** | MS 워드 스타일의 직관적인 텍스트 서식 편집 툴바 제공 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+editing+toolbar+plugin) |
| **notebook-navigator** | 노트 및 폴더 간 탐색과 이동을 편리하게 해주는 네비게이션 기능 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+notebook+navigator+plugin) |
| **obsidian-emoji-toolbar** | 이모지를 쉽게 검색하고 입력할 수 있는 전용 툴바 창 제공 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+emoji+toolbar+plugin) |
| **tasknotes** | 할 일(Tasks)과 노트를 연동하여 효과적인 태스크 관리 지원 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+tasknotes+plugin) |
| **star-notebooklm** | 옵시디언 내에서 Google NotebookLM과 유사한 AI 문서 분석 기능 지원 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+star+notebooklm+plugin) |
| **obsidian-path-title** | 노트 제목에 파일의 현재 경로를 표시하여 위치 파악 도움 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+path+title+plugin) |
| **obsidian-show-file-path** | 화면 하단 상태 표시줄 등에 현재 파일의 전체 경로 표시 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+show+file+path+plugin) |
| **obsidian-file-color** | 파일 탐색기의 폴더나 노트에 색상을 지정하여 시각적 구분 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+file+color+plugin) |
| **obsidian-excel-to-markdown-table** | 엑셀의 표 데이터를 복사하여 마크다운 표 형식으로 바로 붙여넣기 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+excel+to+markdown+table+plugin) |
| **iconic** | 노트 제목이나 파일 탐색기 항목에 아이콘을 추가하여 시각화 | [유튜브 검색](https://www.youtube.com/results?search_query=obsidian+iconic+plugin) |
