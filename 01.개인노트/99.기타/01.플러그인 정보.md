# 🧩 설치된 플러그인 정보

## ⚙️ 내장 기능 (Core Plugins)
| 분류 | 플러그인 이름 | 설명 |
| :--- | :--- | :--- |
| **탐색 및 검색** | 파일 탐색기, 전역 검색, 전환기(Switcher), 명령 팔레트, 개요(Outline) | 핵심적인 내비게이션과 기능 접근 도구 |
| **콘텐츠/관리** | 데일리 노트, 템플릿, 속성(Properties), 북마크, 노트를 제작(Note Composer) | 체계적인 기록 및 관리 지원 |
| **시각화/정보** | 그래프 뷰, 캔버스(Canvas), 태그 창, 페이지 미리보기, 단어 수 세기 | 데이터 시각화 및 정보의 시인성 강화 |
| **시스템/데이터** | 백링크, 외부 링크, 편집 상태, 파일 복구, 동기화, 무작위 노트 선택 | 데이터 연결성 확보 및 시스템 안정성 강화 |
