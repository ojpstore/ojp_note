# VSCode SSH 연결 설정 가이드

## 1. [개인PC] 사전 준비 및 확장 설치
- **확장 프로그램 설치**: VSCode에서 `Remote - SSH` 확장을 설치합니다.

## 2. [개인PC] SSH 키 생성 및 이해
### 키 생성 명령어
```jsx
ssh-keygen 
# 또는 보안 강화 버전 (RSA 4096bit)
ssh-keygen -t rsa -b 4096
```

### 옵션 상세 설명
1. **`ssh-keygen` (기본 실행)**: 시스템 기본값(ed25519 또는 rsa 2048/3072)으로 키 쌍을 생성합니다.
2. **`-t rsa -b 4096`**: 
    - `-t rsa`: 호환성이 뛰어난 RSA 알고리즘 사용.
    - `-b 4096`: 키 길이를 4096비트로 설정하여 보안성을 극대화 (NIST 권장).

### 키 파일의 역할
- **개인키 (Private Key / `id_rsa`)**: '인감도장' 역할을 하며, 내 컴퓨터에만 엄격하게 보관해야 합니다 (권한 600).
- **공개키 (Public Key / `id_rsa.pub`)**: '자물쇠' 역할을 하며, 접속하려는 서버의 `authorized_keys`에 등록하여 사용합니다.

## 3. [개인PC] SSH Config 설정
- **경로**: `C:\Users\계정\.ssh\config`
- **설정 내용**:
```jsx
Host 서버별칭 (예: My-Dev-Server)
  HostName 서버주소 (IP 또는 도메인)
  User 접속계정 (예: root)
  Port SSH포트번호
  IdentityFile C:\Users\계정\.ssh\id_rsa
```

## 4. [원격 서버] 공개키 등록 방법
### 방법 A: PowerShell 명령어로 자동 등록
```jsx
type $env:USERPROFILE\.ssh\id_rsa.pub | ssh 계정@서버주소 "echo '' >> ~/.ssh/authorized_keys; cat >> .ssh/authorized_keys"
```

### 방법 B: 직접 서버 설정 (수동)
- 서버의 `/root/.ssh/authorized_keys` 파일에 로컬에서 생성한 `id_rsa.pub` 파일의 내용을 복사하여 붙여넣습니다.

### ⚙️ 설정 화면 항목 설명
- **Host**: VSCode 목록에서 보여줄 서버의 별칭입니다.
- **HostName**: 접속할 서버의 실제 IP 주소 혹은 도메인입니다.
- **User**: 서버에 로그인할 사용자 계정명입니다.
- **Port**: SSH 서비스가 사용 중인 포트 번호입니다. (기본값: 22)
- **IdentityFile**: 인증에 사용할 개인키(`id_rsa`)의 로컬 경로입니다.
