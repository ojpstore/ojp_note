개인 PC를 VPN 서버로 구축하면 외부에서도 집이나 사무실의 홈 네트워크, 파일, 내부 장치에 안전하게 접속할 수 있습니다.
구축 목적과 네트워크 환경에 따라 가장 간편한 방법(Tailscale)부터 직접 구축하는 전통적인 방식(WireGuard/OpenVPN)까지 선택할 수 있습니다.

## 1. 구축 방식 비교

| **방식**                          | **난이도**    | **포트포워딩(공유기 설정)** | **장점 및 특징**                                                             |
| --------------------------------- | ------------- | --------------------------- | ---------------------------------------------------------------------------- |
| **Tailscale / ZeroTier _(추천)_** | **매우 쉬움** | **불필요**                  | **계정 로그인만으로 즉시 연결, NAT/방화벽 우회, WireGuard 기반의 빠른 속도** |
| **WireGuard 직접 설치**           | 보통          | **필요**                    | 가볍고 매우 빠름, 오픈소스, 최신 암호화 프로토콜                             |
| **OpenVPN**                       | 보통~어려움   | **필요**                    | 안정적이고 검증된 호환성, 설정 옵션이 다양함                                 |
| **Windows 내장 VPN**              | 쉬움~보통     | **필요**                    | 추가 프로그램 설치 최소화 (단, 모바일/타 OS 연결 설정 번거로움)              |

## 2. 추천 방법별 구축 흐름

### 방법 A. Tailscale 활용 (가장 간편하고 안정적)

공유기 설정(포트포워딩, DDNS) 없이 외부에서 접속하고 싶을 때 가장 추천하는 방식입니다.

1. **PC 설정:** [Tailscale 공식 홈페이지](https://tailscale.com/)에서 프로그램을 다운로드하여 설치하고 로그인합니다.
2. **서브넷 라우터 설정 (선택):** PC뿐만 아니라 집안의 다른 기기(NAS, 프린터 등)까지 접근하려면 Tailscale에서 `Subnet Router` 기능을 활성화합니다.
3. **외부 기기 연결:** 스마트폰, 노트북 등에 Tailscale 앱을 설치하고 같은 계정으로 로그인하면 즉시 가상 사설망(VPN)으로 묶입니다.

### 방법 B. WireGuard / OpenVPN 직접 구축 (전통적 방식)

PC를 완전히 독립적인 독립 서버로 운영하고자 할 때 사용합니다.

**1.PC에 VPN 서버 소프트웨어 설치:**

WireGuard 또는 OpenVPN Server 프로그램을 설치하고 클라이언트용 인증서/설정 프로파일(.conf 또는 .ovpn)을 생성합니다.

**2.공유기 포트포워딩 및 DDNS 설정:**공유기 관리자 페이지(192.168.0.1 등)에서 진행.

유동 IP 환경에서도 접속할 수 있도록 공유기에서 **DDNS**를 활성화하고, VPN 포트(WireGuard 기본 UDP 51820 / OpenVPN 기본 UDP 1194)를 PC의 내부 IP로 **포트포워딩**합니다.

**3.방화벽 규칙 허용:**

Windows 방화벽(고급 설정)의 인바운드 규칙에서 해당 VPN 포트를 허용합니다.

**4.외부 기기에서 클라이언트 접속:**

모바일이나 외부 노트북의 VPN 클라이언트 앱에 생성한 프로파일을 등록하고 접속을 테스트합니다.

## 3. PC를 VPN 서버로 쓸 때 필수 체크리스트

- **전원 및 절전 모드 관리:** 외부에서 접속하려면 PC가 항상 켜져 있어야 합니다. Windows 설정에서 절전 모드를 '안 함'으로 변경하고, 공유기의 **WOL(Wake on LAN)** 기능을 설정해 두면 원격으로 PC를 켤 수 있습니다.
- **고정 내부 IP 할당:** 공유기의 DHCP 설정에서 VPN 서버 PC의 사설 IP(예: 192.168.0.100)를 고정해 두어야 재부팅 시 포트포워딩이 풀리지 않습니다.
- **보안:** 외부로 열려 있는 포트가 생기므로 강력한 비밀번호와 인증서 기반 인증을 사용하는 것이 안전합니다.
