# Tailscale VPN 서버 설정

## 1. Windows 기준 설정

### 1. 기본 설치 및 연결

```powershell
# 1. 다운로드 및 설치
# https://tailscale.com/download/windows 에서 다운로드

# 2. 로그인 (자동으로 브라우저 열림)
# Google/Microsoft/GitHub 계정으로 인증

# 3. 현재 상태 확인
tailscale status

# 4. IP 확인
tailscale ip -4
```

### 2. 서브넷 라우터 설정 (집 전체 네트워크 접근)

```powershell
# 1. IP 포워딩 활성화 (관리자 권한 필요)
Set-NetIPInterface -Forwarding Enabled

# 2. 서브넷 광고
tailscale up --advertise-routes=192.168.0.0/24 --accept-routes

# 3. Admin Console에서 승인
# https://login.tailscale.com/admin/machines
# 해당 기기 → Edit route settings → Approve subnet routes
```

### 3. Exit Node 설정 (인터넷 라우팅)

```powershell
# 1. Exit Node로 광고
tailscale up --advertise-exit-node

# 2. Admin Console에서 승인
# Settings → Edit route settings → "Use as exit node" 승인

# 3. Windows 방화벽 설정
# 제어판 → 방화벽 → 고급 설정 → 인바운드 규칙
# "Tailscale" 규칙 모두 허용
```

### 4. 자동 시작 설정

```powershell
# Tailscale은 기본적으로 자동 시작
# 서비스 확인:
Get-Service Tailscale

# 서비스 재시작:
Restart-Service Tailscale
```

## Linux 기준 설정

### 1. 기본 설치 및 연결

```bash
# Ubuntu/Debian
curl -fsSL https://tailscale.com/install.sh | sh

# Arch Linux
sudo pacman -S tailscale

# Fedora/RHEL
sudo dnf install tailscale

# 시작 및 활성화
sudo systemctl enable --now tailscaled
sudo tailscale up

# 상태 확인
tailscale status
tailscale ip -4
```

### 2. 서브넷 라우터 설정

```bash
# 1. IP 포워딩 활성화
echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# 2. 방화벽 설정 (ufw 사용 시)
sudo ufw allow in on tailscale0
sudo ufw route allow in on tailscale0
sudo ufw route allow out on tailscale0

# 3. 서브넷 광고
sudo tailscale up --advertise-routes=192.168.0.0/24 --accept-routes

# 4. Admin Console에서 승인
```

### 3. Exit Node 설정

```bash
# 1. 방화벽 마스커레이딩 설정 (iptables)
sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
sudo iptables-save | sudo tee /etc/iptables/rules.v4

# 또는 ufw 사용 시
sudo nano /etc/ufw/before.rules
# 다음 내용 추가:
# *nat
# :POSTROUTING ACCEPT [0:0]
# -A POSTROUTING -s 100.64.0.0/10 -o eth0 -j MASQUERADE
# COMMIT

# 2. Exit Node로 광고
sudo tailscale up --advertise-exit-node

# 3. Admin Console에서 승인
```

### 4. 자동 시작 설정

```bash
# systemd 서비스 활성화
sudo systemctl enable tailscaled
sudo systemctl status tailscaled

# 부팅 시 자동 연결 (옵션 유지)
sudo tailscale up --authkey=<YOUR_AUTH_KEY> --advertise-exit-node
```

### 5. Headless 서버 설정 (GUI 없는 서버)

```bash
# 1. Auth Key 생성
# https://login.tailscale.com/admin/settings/keys
# "Generate auth key" → "Reusable" 체크

# 2. Auth Key로 자동 로그인
sudo tailscale up --authkey=tskey-auth-xxxxx-xxxxx

# 3. 재부팅 시에도 유지
sudo tailscale up --authkey=tskey-auth-xxxxx-xxxxx --advertise-exit-node
```

## 공통 유용한 명령어

```bash
# 연결 상태 확인
tailscale status

# 네트워크 진단
tailscale netcheck

# Ping 테스트
tailscale ping <기기이름>

# 로그 확인 (Windows)
C:\ProgramData\Tailscale\tailscaled.log

# 로그 확인 (Linux)
sudo journalctl -u tailscaled -f

# 연결 해제
tailscale down

# 완전 로그아웃
tailscale logout

# 업데이트 (Linux)
sudo tailscale update
```

## 성능 비교

| 기능          | Windows              | Linux                    |
| ------------- | -------------------- | ------------------------ |
| Exit Node     | ⚠️ 느림 (NAT 제한)   | ✅ 빠름                  |
| 서브넷 라우터 | ✅ 정상              | ✅ 정상                  |
| 24시간 구동   | ⚠️ 업데이트로 재부팅 | ✅ 안정적                |
| 전력 소모     | 높음                 | 낮음 (라즈베리파이 가능) |
| 권장 용도     | 클라이언트           | 서버/라우터              |

## 추천 구성

**최적의 홈 VPN 구성:**

- **라즈베리파이 (Linux)**: Exit Node + 서브넷 라우터
- **Windows PC**: 클라이언트로만 사용
- **스마트폰**: 외출 시 연결

```bash
# 라즈베리파이 설정 예시
sudo tailscale up \
  --advertise-exit-node \
  --advertise-routes=192.168.0.0/24 \
  --accept-routes \
  --hostname=home-gateway
```
