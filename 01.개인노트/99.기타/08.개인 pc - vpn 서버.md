# 개인 PC VPN 서버 구축 가이드

개인 PC를 VPN 서버로 구축하면 외부에서도 집이나 사무실의 홈 네트워크, 파일, 내부 장치에 안전하게 접속할 수 있습니다.

## 1. 구축 방식 비교

| **방식**                         | **난이도**    | **포트포워딩** | **장점**                                             | **단점**                          |
| -------------------------------- | ------------- | -------------- | ---------------------------------------------------- | --------------------------------- |
| **Tailscale _(추천)_**           | **매우 쉬움** | **불필요**     | 설치 후 즉시 사용, NAT 우회, 무료(개인용), 빠른 속도 | 외부 서비스 의존                  |
| **ZeroTier**                     | 매우 쉬움     | 불필요         | Tailscale과 유사, 오픈소스                           | Tailscale보다 약간 느림           |
| **WireGuard**                    | 보통          | **필요**       | 매우 빠름, 가벼움, 최신 암호화, 오픈소스             | 직접 설정 필요                    |
| **OpenVPN**                      | 보통~어려움   | **필요**       | 검증된 안정성, 다양한 설정 옵션, 광범위한 호환성     | 상대적으로 느림, 설정 복잡        |
| **Windows 내장 VPN (SSTP/L2TP)** | 쉬움          | **필요**       | 추가 프로그램 불필요                                 | 기능 제한적, 모바일 설정 번거로움 |

## 2. 방법별 상세 가이드

### 🌟 방법 A. Tailscale (가장 추천)

**공유기 설정 없이 5분 만에 구축 가능**

#### 1단계: PC 설정

1. [Tailscale 공식 사이트](https://tailscale.com/) 접속
2. Windows용 클라이언트 다운로드 및 설치
3. Google/Microsoft 계정으로 로그인
4. 자동으로 가상 IP 할당됨 (예: `100.x.x.x`)

#### 2단계: 서브넷 라우터 설정 (선택사항)

**집안의 다른 기기(NAS, 프린터 등)에도 접근하려면:**

```powershell
# 관리자 권한 PowerShell에서 실행
tailscale up --advertise-routes=192.168.0.0/24 --accept-routes
```

- Tailscale 웹 관리 페이지에서 해당 기기의 서브넷 라우팅 승인 필요
- `192.168.0.0/24`는 자신의 내부 네트워크 대역에 맞게 수정

#### 3단계: 외부 기기 연결

- 스마트폰/노트북에 Tailscale 앱 설치
- 같은 계정으로 로그인 → 즉시 연결 완료
- 할당받은 IP로 RDP, 파일 공유 등 접속

#### 장점

- ✅ 공유기 설정 불필요
- ✅ 유동 IP 상관없음
- ✅ NAT/방화벽 자동 우회
- ✅ 무료 (개인용 100대까지)

#### 👍 서브넷 라우터 설정 (선택사항)

**집안의 다른 기기(NAS, 프린터 등)에도 접근하려면:**

##### Windows PC를 서브넷 라우터로 사용

```powershell
# 관리자 권한 PowerShell에서 실행
tailscale up --advertise-routes=192.168.0.0/24 --accept-routes
```

- Tailscale 웹 관리 페이지에서 해당 기기의 서브넷 라우팅 승인 필요
- `192.168.0.0/24`는 자신의 내부 네트워크 대역에 맞게 수정

##### Linux 기기를 서브넷 라우터로 사용 (권장)

**우분투/라즈베리파이 등 24시간 가동 기기가 있다면 더 효율적**

**1) IP 포워딩 활성화**

```bash
echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf
```

**2) 서브넷 라우팅 광고**

```bash
sudo tailscale up --advertise-routes=192.168.1.0/24 --accept-routes
```

- 내부망 대역을 실제 환경에 맞게 수정 (예: `192.168.0.0/24`, `10.0.0.0/24`)

**3) Tailscale 관리 콘솔에서 승인**

1. [Tailscale Admin Console](https://login.tailscale.com/admin/machines) 접속
2. 해당 기기 우측 `···` 클릭 → **Edit route settings**
3. **Subnet routes** 목록에서 IP 대역 체크박스 활성화 → 저장

**4) 외부 클라이언트 설정**

- **Windows/macOS/모바일**: 자동 적용, 추가 설정 불필요
- **Linux 클라이언트**: 아래 명령어 실행 필요
  ```bash
  sudo tailscale up --accept-routes
  ```

**⚠️ IP 충돌 방지 팁**

외부에서 접속할 때 현재 위치(카페, 다른 집 등)의 내부망 대역이 원격지와 같으면 충돌이 발생합니다.

- ❌ 원격지: `192.168.0.0/24` / 현재 위치: `192.168.0.0/24` → 충돌
- ✅ 원격지: `192.168.50.0/24` 또는 `10.0.10.0/24` → 충돌 없음

**해결책**: 원격지 공유기 설정에서 흔하지 않은 대역으로 변경

### 🔧 방법 B. WireGuard 직접 구축

**완전한 통제권과 오픈소스를 원할 때**

#### 1단계: WireGuard 서버 설치 (Windows PC)

1. [WireGuard 다운로드](https://www.wireguard.com/install/)
2. 설치 후 관리자 권한으로 실행
3. "빈 터널 추가" 클릭 → 자동으로 키 페어 생성

#### 2단계: 서버 설정 파일 작성

**예시: `wg0.conf`**

```ini
[Interface]
PrivateKey = <서버 개인키>
Address = 10.0.0.1/24
ListenPort = 51820

# 클라이언트 1
[Peer]
PublicKey = <클라이언트1 공개키>
AllowedIPs = 10.0.0.2/32

# 클라이언트 2
[Peer]
PublicKey = <클라이언트2 공개키>
AllowedIPs = 10.0.0.3/32
```

#### 3단계: 공유기 설정

**A. DDNS 설정**

- 공유기 관리 페이지(예: `192.168.0.1`) 접속
- DDNS 메뉴에서 무료 서비스 선택 (No-IP, DuckDNS 등)
- 도메인 등록 (예: `myhome.duckdns.org`)

**B. 포트포워딩**

- 외부 포트: `51820` (UDP)
- 내부 IP: `192.168.0.100` (PC 고정 IP)
- 내부 포트: `51820`

#### 4단계: Windows 방화벽 설정

```powershell
# 관리자 권한 PowerShell
New-NetFirewallRule -DisplayName "WireGuard" -Direction Inbound -Protocol UDP -LocalPort 51820 -Action Allow
```

#### 5단계: 클라이언트 설정

**모바일/외부 PC 설정 파일 예시:**

```ini
[Interface]
PrivateKey = <클라이언트 개인키>
Address = 10.0.0.2/24
DNS = 1.1.1.1

[Peer]
PublicKey = <서버 공개키>
Endpoint = myhome.duckdns.org:51820
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25
```

### 🔐 방법 C. OpenVPN 구축

#### 1단계: OpenVPN 서버 설치

- [OpenVPN Community Edition](https://openvpn.net/community-downloads/) 다운로드
- 설치 시 "EasyRSA" 옵션 포함

#### 2단계: 인증서 생성

```cmd
# EasyRSA 폴더에서 실행
cd "C:\Program Files\OpenVPN\easy-rsa"
EasyRSA-Start.bat

# CA 초기화
./easyrsa init-pki
./easyrsa build-ca nopass

# 서버 인증서
./easyrsa build-server-full server nopass

# 클라이언트 인증서
./easyrsa build-client-full client1 nopass

# DH 파라미터 생성 (시간 소요)
./easyrsa gen-dh
```

#### 3단계: 서버 설정

- 공유기 포트포워딩: UDP `1194` → PC 내부 IP
- Windows 방화벽 UDP 1194 허용
- 서버 설정 파일 작성 (`server.ovpn`)

#### 4단계: 클라이언트 연결

- `.ovpn` 프로파일을 모바일/PC에 배포
- OpenVPN Connect 앱으로 접속

## 3. 필수 체크리스트

### ⚙️ PC 설정

- [ ] **전원 관리**
  - Windows 설정 → 시스템 → 전원 → "절전 모드": 안 함
  - 고급 전원 설정 → "하드 디스크 끄기": 안 함

- [ ] **고정 IP 할당**
  - 공유기 DHCP 예약으로 PC MAC 주소에 고정 IP 할당
  - 예: `192.168.0.100`

- [ ] **WOL (Wake on LAN) 설정** _(선택사항)_
  ```
  1. BIOS에서 WOL 활성화
  2. 네트워크 어댑터 속성 → 전원 관리 → "Magic Packet으로 깨우기" 체크
  3. 공유기에서 WOL 지원 확인
  ```

### 🔒 보안

- [ ] **강력한 인증**
  - WireGuard/OpenVPN: 키 기반 인증 사용
  - Tailscale: 2FA 활성화

- [ ] **방화벽 규칙 최소화**
  - 필요한 포트만 열기
  - 가능하면 Fail2Ban 등 침입 방지 도구 사용

- [ ] **정기 업데이트**
  - VPN 소프트웨어 최신 버전 유지
  - Windows 보안 패치 적용

### 📊 모니터링

- [ ] 외부 IP 변경 알림 설정 (DDNS 사용 시)
- [ ] VPN 연결 로그 주기적 확인
- [ ] 비정상 접속 시도 모니터링

## 4. 문제 해결

### 연결이 안 될 때

**1. 포트포워딩 확인**

```
외부에서 확인: https://www.yougetsignal.com/tools/open-ports/
내부 IP와 포트가 제대로 포워딩되었는지 테스트
```

**2. 방화벽 확인**

```powershell
# Windows 방화벽 규칙 확인
Get-NetFirewallRule | Where-Object {$_.DisplayName -like "*WireGuard*"}
```

**3. 공인 IP 확인**

```
DDNS 도메인이 현재 공인 IP와 일치하는지 확인
nslookup myhome.duckdns.org
```

### 속도가 느릴 때

- UDP 포트 차단 확인 (일부 ISP는 UDP 제한)
- WireGuard의 MTU 값 조정 (`MTU = 1420` → `1280`)
- QoS 설정으로 VPN 트래픽 우선순위 조정

### Tailscale 연결 불안정

- DERP 릴레이 서버 변경
- Direct connection 확인: `tailscale status`
- 네트워크에서 UDP 차단 여부 확인

## 💡 추가 팁

### 성능 최적화

- **WireGuard**: CPU 사용량 낮고 배터리 효율적
- **멀티코어 활용**: OpenVPN보다 WireGuard가 유리
- **암호화 부담**: AES-NI 지원 CPU 권장

### 비용 고려

- **Tailscale**: 개인용 무료 (가장 경제적)
- **전력 소비**: 24시간 가동 시 월 3,000~5,000원 수준
- **고정 IP**: 통신사 고정 IP 서비스는 월 1~2만원 (DDNS로 대체 가능)

### 백업 방안

- VPN 방식 2개 병행 (예: Tailscale + WireGuard)
- 하나 실패 시 다른 경로로 접속 가능
