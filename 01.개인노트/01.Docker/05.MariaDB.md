- 컨테이너 생성 및 실행
```docker
docker run --name mariadb -e MYSQL_ROOT_PASSWORD=비밀번호 -p 3306:3306 -v D:\docker\mariadb:/var/lib/mysql mariadb  --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
```
