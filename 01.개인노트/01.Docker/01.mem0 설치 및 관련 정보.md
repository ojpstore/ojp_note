## 1\. 사전 준비

설치를 진행하기 전, 시스템에 **Docker** 와 **Docker Compose** 가 설치되어 있어야 합니다.

## 2\. Docker Compose로 설치하기 (가장 추천)

Mem0는 데이터 저장을 위해 Vector 데이터베이스(예: Qdrant) 등이 필요할 수 있으므로, `docker-compose` 를 사용하는 것이 가장 깔끔하고 관리하기 쉽습니다.

### 단계 1: 프로젝트 디렉터리 생성 및 이동

터미널을 열고 Mem0를 위한 디렉터리를 만듭니다.

```
mkdir mem0-docker && cd mem0-docker
```

### 단계 2: docker-compose.yml 파일 생성

원하는 텍스트 에디터(nano, vim 등)를 이용해 `docker-compose.yml` 파일을 생성하고 아래 내용을 붙여넣습니다.

```
version: '3.8'

services:
  mem0:
    image: mem0ai/mem0:latest
    ports:
      - "8000:8000"
    environment:
      - OPENAI_API_KEY=your_openai_api_key_here
      # 필요에 따라 다른 LLM 공급자나 설정 파라미터를 추가할 수 있습니다.
    restart: always
```

> ⚠️ **주의:** `your_openai_api_key_here` 부분에 실제 OpenAI API 키를 입력하거나, 사용하고자 하는 LLM 설정을 환경변수로 넣어주셔야 합니다.

### 단계 3: 컨테이너 실행

다음 명령어를 입력하여 백그라운드에서 컨테이너를 실행합니다.

```
docker compose up -d
```

## 3\. Docker CLI로 직접 실행하기

컨테이너 하나만 빠르게 테스트해보고 싶다면 아래 명령어로 직접 실행할 수도 있습니다.

```
docker run -d \
  -p 8000:8000 \
  -e OPENAI_API_KEY="your_openai_api_key_here" \
  --name mem0-service \
  mem0ai/mem0:latest
```

## 4\. 설치 확인 및 테스트

서버가 정상적으로 떴는지 확인하려면 웹 브라우저나 `curl` 명령어를 통해 API 헬스체크를 진행합니다.

```
curl http://localhost:8000/health
```

정상적으로 작동한다면 서비스 상태가 양호하다는 응답(예: `{"status": "ok"}`)을 받게 됩니다. 이후 Mem0 파이썬 클라이언트나 HTTP 요청을 통해 메모리 추가/조회 기능을 사용하시면 됩니다.


## 5\. Mem0 Docker 설정 변경 확인

먼저, 앞서 작성한 Docker 환경에서 Hermes Agent가 접근할 수 있도록 포트와 호스트가 잘 열려있는지 확인합니다.

만약 동일한 서버(예: 내 로컬 PC)에서 Hermes Agent와 Mem0를 같이 실행한다면 주소는 `http://localhost:8000` 이 됩니다. (별도 인증 키를 설정하지 않았다면 API\_KEY는 임의의 더미 값을 사용하거나, Mem0 컨테이너에 설정한 값을 사용합니다.)

## 6\. Hermes Agent에 Mem0 연결하기

Hermes Agent 구성 파일(`config.yaml`)에 설정을 추가하거나 환경 변수로 넘겨주는 방식을 사용할 수 있습니다.

### 방법 A: config.yaml 파일 수정 (가장 추천)

Hermes Agent의 설정 폴더(일반적으로 `~/.hermes/config.yaml`)를 열고 아래와 같이 외부 메모리 제공자(Memory Provider) 설정을 추가합니다.

```
# ~/.hermes/config.yaml

memory:
  provider: "mem0"
  config:
    # Docker로 띄운 Mem0 서버 주소 주입
    host: "http://localhost:8000" 
    # self-hosted 버전에서 별도 auth가 없다면 임의의 문자열 입력 가능
    api_key: "your-mem0-api-key"
```

### 방법 B: CLI 명령어로 설정하기

터미널에서 Hermes의 내장 설정 프롬프트를 이용하여 대화식으로 연결할 수도 있습니다.

```
hermes memory setup
```

위 명령어를 입력한 뒤, 제공자로 `mem0` 를 선택하고 호스트 주소(`http://localhost:8000`)와 API Key를 차례대로 입력합니다.

### 방법 C: 환경 변수(Environment Variables)로 직접 주입

Hermes Agent를 터미널이나 별도 Docker 컨테이너로 띄울 때 환경 변수를 직접 넘겨줄 수도 있습니다.

```
export MEM0_HOST="http://localhost:8000"
export MEM0_API_KEY="your-mem0-api-key"
```

## 3\. 연결 확인 및 테스트

설정을 마친 후 Hermes Agent를 재시작합니다. 그 다음 Hermes와의 대화에서 메모리 기능이 작동하는지 테스트해 봅니다.

1. **테스트 프롬프트 입력:** > "내 이름은 서비스 가이드봇이고, 커피는 아메리카노만 마셔."
2. **Mem0 백엔드 로그 확인:** Mem0 Docker 컨테이너 로그(`docker logs -f mem0-service`)를 보면, Hermes가 전송한 대화 내용에서 사실(Fact)을 자동 추출하여 저장하는 LLM 연동 로그를 확인할 수 있습니다.
3. **기억 소환 테스트:** > "내가 어떤 커피 좋아한다고 했지?" 라고 물었을 때, Hermes가 Mem0의 벡터 검색 데이터를 읽어와 올바르게 답변하면 연결이 완전히 성공한 것입니다.
