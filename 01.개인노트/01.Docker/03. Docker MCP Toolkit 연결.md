### 1. 일반적인 `mcpServers` 구조 (Claude Desktop 등)

가장 보편적인 AI 에이전트/클라이언트(예: Claude Desktop의 `claude_desktop_config.json`)에 연결할 때 사용하는 형태입니다.

JSON

```
{
  "mcpServers": {
    "Docker_MCP_Work": {
      "command": "docker",
      "args": [
        "mcp",
        "gateway",
        "run",
        "--profile",
        "work"
      ]
    }
  }
}
```

- **`--profile work`**: 이미지에 명시된 `work` 프로필 내의 모든 서버들(설치된 5개 이상의 서버)을 이 하나의 게이트웨이 명령어로 한 번에 불러옵니다.
    

### 2. VS Code (`mcp.json`) 구조

이미지 오른쪽의 Clients 항목이나 VS Code 내 환경 파일(`.vscode/mcp.json`)에 적용할 때는 다음과 같은 표준 형태를 가집니다.

JSON

```
{
  "mcp": {
    "servers": {
      "MCP_DOCKER_WORK": {
        "command": "docker",
        "args": [
          "mcp",
          "gateway",
          "run",
          "--profile",
          "work"
        ],
        "type": "stdio"
      }
    }
  }
}
```

### 💡 팁: 터미널 명령어로 자동 연결하기

매뉴얼하게 JSON을 편집하는 것이 번거롭다면, Docker CLI가 제공하는 자동 연결 명령어를 터미널(또는 작업 중인 프로젝트 디렉토리)에서 실행하면 설정 파일이 알아서 생성되거나 갱신됩니다.

- **VS Code 자동 연결 명령어**:
    
    Bash
    
    ```
    docker mcp client connect vscode --profile work
    ```
    
    _(해당 프로젝트 폴더에 `.vscode/mcp.json` 파일이 자동으로 생성됩니다.)_
    
- **Claude Desktop 자동 연결 명령어**:
    
    Docker Desktop의 **Clients** 탭에서 Claude Desktop 옆의 **[Connect]** 버튼을 누르면 설정 파일에 자동으로 위 JSON 내용이 삽입됩니다.
