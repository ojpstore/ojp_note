## 🛠️ Claude Code에 Ponytail 설치하기

AI 코딩 에이전트가 불필요한 설계를 지양하고, 핵심 기능에만 집중하여 최소한의 코드만 작성하도록 강제하는 **Ponytail(포니테일)** 플러그인입니다.
```bash
# 1. 마켓플레이스에 Ponytail 플러그인 추가
/plugin marketplace add DietrichGebert/ponytail

# 2. Ponytail 플러그인 설치
/plugin install ponytail@ponytail
```

> **💡 Claude Code 데스크톱 앱 사용자 안내**
> 앱 내 **Code** 탭 프롬프트 창에 직접 입력하거나, `+` 버튼 ➔ `Plugins` ➔ `Add plugin` 메뉴를 통해 마켓플레이스에서 설치할 수 있습니다.

## ⚙️ Ponytail 주요 명령어 및 활용법

설치가 완료되면 Claude Code 세션 내에서 전용 명령어(`/`)를 사용하여 기능을 제어합니다.

### 1. 작동 강도 조절 (`/ponytail`)
AI 에이전트의 코드 절약(YAGNI 원칙) 적용 수준을 4단계로 설정합니다.
- `/ponytail full`: 기본 활성화 상태 (기본값)
- `/ponytail ultra`: 극단적인 코드 최소화 및 네이티브 기능 우선 사용 강제
- `/ponytail lite`: 약간의 유연성을 허용하며 작동
- `/ponytail off`: 기능을 비활성화

### 2. 코드 다이어트 검토 (`/ponytail-review`)
현재 수정된 Diff에서 오버엔지니어링된 부분을 찾아내고, 외부 라이브러리 대신 표준/네이티브 코드로 대체 가능한 부분이 있는지 검토합니다.

### 3. 전체 저장소 감사 (`/ponytail-audit`)
프로젝트 전체를 분석하여 불필요하게 복잡한 추상화 레이어나 과도한 의존성을 찾아내고 리포트를 생성합니다.

## 🧐 작동 원리 (The Decision Ladder)

Ponytail이 활성화되면 Claude Code는 코드를 작성하기 전 **'의사결정 사다리(Decision Ladder)'**를 거칩니다.

예를 들어 *"날짜 선택기(Date Picker)"* 요청 시:
- **일반 모드:** `flatpickr` 같은 외부 라이브러리 설치 및 복잡한 래퍼 컴포넌트 구현
- **Ponytail 활성화:** 브라우저 네이티브 태그인 `<input type="date">`로 즉시 처리

**효과:** 토큰 소모량 감소 → API 비용 절감 및 결과 도출 속도 향상.
