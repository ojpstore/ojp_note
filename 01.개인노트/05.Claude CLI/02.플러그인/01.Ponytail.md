## 🛠️ Claude Code에 Ponytail 설치하기

AI 코딩 에이전트가 오버엔지니어링을 하지 않고 가장 게으른 시니어 개발자처럼 꼭 필요한 최소한의 코드만 작성하도록 강제하는 **Ponytail(포니테일)** 스킬을 Claude Code(클로드 코드)에 연동하는 방법입니다.

Bash

```
# 1. 마켓플레이스에 Ponytail 플러그인 추가
/plugin marketplace add DietrichGebert/ponytail

# 2. Ponytail 플러그인 설치
/plugin install ponytail@ponytail
```

> **💡 Claude Code 데스크톱 앱을 사용하는 경우:** 앱 내의 **Code** 탭 프롬프트 창에 위 명령어를 그대로 입력하거나, 프롬프트 입력창 옆의 `+` 버튼 ➔ `Plugins` ➔ `Add plugin` 메뉴를 통해 마켓플레이스를 관리하고 설치할 수 있습니다.

## ⚙️ Ponytail 주요 명령어 및 활용법

Pi Coding Agent

설치가 완료되면 Claude Code 세션 내에서 다음과 같은 전용 명령어(`/`)들을 사용할 수 있게 됩니다.

### 1. 작동 강도 조절 (`/ponytail`)

ClaudePluginHub

AI 에이전트의 코드 절약 정신(YAGNI 원칙)을 얼마나 강하게 적용할지 네 단계로 제어합니다.

YouTube

- `/ponytail full` : 기본 활성화 상태입니다.
- `/ponytail ultra` : 극단적으로 코드를 아끼고 네이티브 기능만 쓰도록 강제합니다.
- `/ponytail lite` : 조금 더 유연하게 작동합니다.
- `/ponytail off` : 기능을 잠시 끕니다.

### 2. 코드 다이어트 검토 (`/ponytail-review`)

현재 수정한 Diff(변경 사항) 중에서 오버엔지니어링된 부분이 있는지, 외부 라이브러리 대신 표준 라이브러리나 네이티브 코드로 대체해 삭제할 수 있는 코드가 있는지 집중적으로 리뷰해 줍니다.

### 3. 전체 저장소 감사 (`/ponytail-audit`)

GeekNews

현재 프로젝트 코드베이스 전체를 훑으며 쓸데없이 복잡하게 설계된 추상화 레이어나 불필요한 의존성을 찾아내 보고서를 만들어 줍니다.

## 🧐 작동 원리 (The Decision Ladder)

Ponytail이 적용되면 Claude Code는 코드를 짜기 전에 내부적으로 6단계 사다리 검증을 거칩니다. 예를 들어 *"날짜 선택기(Date Picker)를 만들어줘"*라고 요청하면 일반 Claude Code는 `flatpickr` 같은 패키지를 설치하고 수십 줄의 래퍼 컴포넌트를 구현하려 들지만, Ponytail이 켜져 있으면 **브라우저 네이티브 태그인 `<input type="date">` 단 한 줄**로 끝내버립니다.

이를 통해 토큰 소모량을 대폭 줄여 API 비용을 아끼고 결과물 도출 속도도 빨라집니다.
